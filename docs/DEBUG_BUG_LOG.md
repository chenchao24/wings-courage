## #30 坠毁前向动量保留：突然失速（2026-08-02）

**现象**：被击落的飞机失速太快，未保持击落前的向前动量，看起来都是突然失速然后下坠，不符合真实物理。

**根因**（弹道模式为主）：
1. **机头低头太快**：`_crashPitchRate = 0.7 + 0.3` rad/s，约 1.1 秒机头就低头到近垂直（π/2≈1.57），视觉上像"突然失速垂直下坠"。
2. **水平阻力过大**：`_crashVel.x/z *= (1 - dt * 0.15)`，前向动量快速衰减。
3. **3 倍重力下坠过快**：`_crashSinkRate = gravity * 3.0`，下坠过快，前向动量还没体现就落地了。
4. **向上分量直接归零**：`if (this._crashVel.y > 0) this._crashVel.y = 0`，爬升中被击落会瞬间丢失向上惯性。
5. **挣扎模式只保留 80% 前飞速度**，且减速 0.08/s。

**真实物理**：飞机被击落后由于惯性保持前向动量，沿抛物线下坠（前向+重力下降），机头因失去升力缓慢下垂，而非瞬间垂直。

**修复**（`aircraft.js _startCrash` / `_updateCrash`）：
- **弹道模式**：
  - 重力 3.0 → 1.5 倍（抛物线下坠）
  - 机头低头 0.7-1.0 → 0.25-0.4 rad/s（4-6s 到近垂直）
  - 阻力改整体 0.05/s（`multiplyScalar(1 - dt*0.05)`，保留前飞动量，不再单独衰减水平分量）
  - 向上分量 0.3× 而非归零（保留爬升惯性）
- **挣扎模式**：
  - 前飞保留 0.8 → 0.9
  - 减速 0.08 → 0.04/s
  - 重力 2.0 → 1.5 倍

**验算**（600m 平飞击落，speed=80）：
- 下坠时间 ≈ √(2×600/(1.5×9.8)) ≈ 9 秒
- 水平滑行 ≈ 500m（考虑阻力后平均速度 ~56 m/s）
- 形成明显抛物线轨迹

## #29 坠毁旋转翻转 + 高空漂浮（2026-08-02）

**现象**：被击落的敌机旋转后机头朝上，然后飘在空中不坠落。

**根因**（两条）：
1. **恒定滚转率累积翻转**：`rotateZ(rate * dt)` 每帧累加，10 秒后翻转 172°，机头从朝下变朝上。
2. **挣扎模式恒速下沉**：`position.y -= sinkRate * dt`（8 单位/秒），从 600m 需 75 秒触地，观感"飘"。

**修复**（`aircraft.js _updateCrash`）：
1. 滚转/偏航改 **sin 振荡**：`rotateZ(sin(t * 2.5) * rate * dt)`，不累积，总滚转仅 ±5-9°。
2. 挣扎模式改 **加速下沉**：`_crashVel.y += sinkRate * dt` 累积，`position.y -= _crashVel.y * dt`，12 秒触地。
3. 俯仰振荡幅度 0.2 → 0.15，确保不抬头。

弹道与挣扎两模式滚转/偏航均改 sin 振荡。

## #28 坠毁双模式引入（2026-08-02）

**需求**：被击落的飞机机头应朝下；且有一定概率部分飞机 HP=0 后仍可前飞、小幅度机动，但高度快速下降坠地。

**实现**（`aircraft.js _startCrash`）：随机 30% 选 struggle 模式，70% 选 ballistic 模式。
- 弹道模式：机头快速低头（0.7-1.0 rad/s）至近垂直俯冲（noseDown < 0.9 停止），3 倍重力弹道坠毁。
- 挣扎模式：保留 80% 前飞速度沿机头水平方向，2 倍重力快速下降，小幅度滚转摇晃 ±0.2 + 偏航 ±0.125 + 俯仰振荡 `sin(t*3)*0.2`，缓慢低头 0.15-0.25 rad/s。

详见 [DESIGN.md §7](./DESIGN.md#7-坠毁双模式_startcrash--_updatecrash)。

## #27 坠毁弹道修复：机头上仰时向上螺旋飞（2026-08-02）

**现象**：击落瞬间机头朝上的飞机，开始向上做螺旋运动，没有直接坠向地面。

**根因**：沿机头方向运动 + 螺旋旋转，导致轨迹跟随旋转的机头（螺旋朝上时飞机向上飞）。

**修复**（`aircraft.js _startCrash` / `_updateCrash`）：改为弹道模型——
1. 速度向量 `_crashVel` 坠毁瞬间固定一次（水平惯性）。
2. 重力只改 y 分量（`_crashVel.y -= gravity * 3 * dt`）。
3. 机头螺旋（`rotateX/Y/Z`）纯视觉，不影响轨迹。
4. `_startCrash` 消除向上分量（`if y > 0 则归零`）+ 初始下沉（`y -= gravity * 1`），保证爬升中击落也立即下坠。
5. 水平阻力 0.15/s 逐渐失速，垂直 3 倍重力无阻力加速。

## #26 坠毁加速感强化：仍"飘"（2026-08-02）

**现象**：#25 修复后仍有漂浮感。

**根因**：固定向量 `_crashVel` + 阻力模型（阻力 0.3/s 把动量杀光导致飘）。

**修复**：改为标量 `_crashSpeed` 沿机头方向（`getForward`）持续加速——
- 3 倍重力加速（`_crashSpeed += gravity * 3 * dt`）无阻力。
- 始终叠加重力下沉（`position.y -= gravity * 1 * dt`）保证任何姿态都有下落感。
- 机头低头速率提至 0.6-0.9 rad/s 更快下压。
- 轨迹 = 沿机头加速运动 + 重力下沉，机头下压使轨迹弧线坠地，无漂浮感。

## #25 坠毁物理自然化 + 坠落与重生解耦（2026-08-02）

**现象**：HP=0 后"动作飘"，不是马上变成漂浮状态，要自然过渡；坠落没完成就消失（重生时间问题）。

**根因**：
1. 重力仅 0.7×，下降太慢。
2. 旋转用欧拉角 `rotation.x +=`，跳变。
3. 坠落用固定 6s 计时器强制 `reset()`，导致半空消失。

**修复**（`aircraft.js`）：
1. 重力 0.7× → 2.0× 加速下降。
2. 旋转从欧拉角改为四元数（`rotateX/Y/Z`）避免跳变。
3. 机头渐下压至近垂直俯冲（俯角 < 0.9 时持续低头）。
4. 前向阻力 0.3/s 防滑翔。
5. **坠落过程不再用固定计时器强制 reset**，改为触地 → 爆炸 → 3s 粒子淡出 → 重生；仅 `_exploded` 且计时器归零才 reset。
6. 30s 安全阀防异常永不触地。
7. 每架敌机独立实例，支持未来多敌机。

## #22 座舱位置偏移（2026-08-02）

**现象**：玩家座舱位置发生变化。

**根因**：之前为解决 `tune_enemy` 调试页「轴不在飞机中心」问题，在 `aircraft.js` 的 `_applyCalibration()` 中添加了缩放时重新居中模型（更新 `model.position`）的逻辑，导致主游戏中模型相对于 root 原点的位置改变，而座舱相机偏移（Y=1.65, Z=-0.70）是按原模型位置校准的。

**修复**（`aircraft.js:220-222`）：
- 恢复原逻辑——`_applyCalibration()` **只设缩放，不动 `model.position`**。
- 位置在 `_normalize()` 中一次性设好，座舱偏移据此校准。
- `tune_enemy.js` 的居中逻辑保留不变（调试页独立）。

**教训**：调试页与主游戏共用基类时，调试页专用的居中逻辑不能污染基类的通用方法。座舱偏移依赖 `model.position` 的稳定性。**这条约定已写入 [DESIGN.md §3.10](./DESIGN.md#310-座舱位置约定重要)**。
