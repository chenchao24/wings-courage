## 二、每门炮参数

| 参数 | 配置键 | 当前值 | 说明 |
|------|--------|--------|------|
| 覆盖半径 | `gun.coverage` | 600m | 玩家在此范围内才开火 |
| 最低射高 | `gun.altMin` | 300m | 统一 |
| 最大射高 | `gun.altMax` | 1500m | 统一 |
| 密度系数 | `gun.density` | 0.2 | 每门炮贡献的密度 |
| 齐射频率 | `gun.burstRate` | 0.1 次/秒 | 每门炮独立累积 |
| 曳光弹频率 | `gun.tracerRate` | 0.9 条/秒 | 每门炮独立累积 |

### 实际发射速率
- **后方防空带**（4门）：齐射 4×0.1=0.4 次/秒，曳光弹 4×0.9=3.6 条/秒
- **战场防空**（3门）：齐射 3×0.1=0.3 次/秒，曳光弹 3×0.9=2.7 条/秒
- **阵地防空带**：继承老苏军系数，齐射 1×1.6=1.6 次/秒，曳光弹 12×1.6=19.2 条/秒

### 烟团动画曲线（28s 寿命，两段淡出）
- 0-0.5s：淡入（0 → 峰值）
- 0.5-3s：满可见（峰值）
- 3-20s：缓慢淡出到 0.7（第一段淡出）
- 20-28s：从 0.7 快速淡出到 0（第二段淡出）
- 膨胀：前 20% 时间膨胀到 1.5 倍，之后维持

## 六、爆炸音效

| 参数 | 代码位置 | 当前值 | 说明 |
|------|----------|--------|------|
| 最大播放距离 | `audio.js` `flakExplosion` | 200m | 超过此距离不播放 |
| 距离衰减曲线 | `audio.js` `flakExplosion` | `(1-d/200)^1.5` | 近距离更响，远距离快速衰减 |
| 限频间隔 | `audio.js` `_lastFlak` | 0.05s | 防止密集爆音叠加 |
| 闷响噪声 | 低通滤波 350→40Hz | 0.5s 衰减 | 空中爆炸缺少地面反射，更低更闷 |
| 低频冲击波 | sine 50→20Hz | 0.35s 衰减 | 闷响冲击 |
| 音量总线 | `_sfxBus` | 跟随音效音量设置 | 与命中/坠毁爆炸共用 |

### 程序化合成 vs 文件替换
- **当前**：程序化合成（无外部文件）
- **后续替换**：调用 `audio.loadFlakSound(url)` 加载音频文件，加载后自动优先播放文件
- **恢复合成**：`audio.clearFlakSamples()`（关卡结束时已自动调用）

## 九、调优指南

### 想让某类区域更密 / 更稀
- 阵地防空带：改 `positionDensity`（如 2.0 更密）
- 后方/战场防空：改 `rearGunsPerZone` / `battlefieldGunsPerZone`（如 6 更密）

### 想让炮的覆盖范围更大 / 更小
- 改 `gun.coverage`（如 800 更大）

### 想让每门炮射速更快 / 更慢
- 改 `gun.burstRate` 和 `gun.tracerRate`

### 想让烟团更浓 / 更淡
- 改代码 `js/AntiAircraftFlak.js` 的 `_updateBursts` 里 `op * 0.5`（如 0.7 更浓、0.3 更淡）

### 想让曳光弹更多 / 更少
- 改 `gun.tracerRate`（如 1.5 更多）
- 注意：仅玩家高度 < 500m 时才发射

### 想让爆炸声更近 / 更远
- 改代码 `js/audio.js` 的 `flakExplosion` 里 `maxDist`（如 300 更远可听）

### 想让坦克更密 / 更稀
- 改 `tanksPerKm`（如 6 更密）或 `tankSpacing`（如 500 更密）

## 十一、柏林 corridor 走廊模式（我方防空，打轰炸机编队）

> 配置位置：`js/config/levels/level_04_berlin.js` 的 `flak.corridor` 块
> 逻辑入口：`js/AntiAircraftFlak.js` `_updateCorridor`（配置 `corridor` 才启用；缺省=上文的"跟随玩家"行为，其他关不受影响）

第 4 关的防空炮是**我方**柏林防空军，目标是轰炸机编队，纯表演（不接伤害、不计玩家积分）。与库尔斯克"敌方防空炮跟随玩家"完全两套逻辑。

### 触发机制
- 走廊沿 x 轴 `zoneMin ~ zoneMax`（-30000 ~ 15000，东缘=编队入口），从东缘向西每 `segmentEvery`（3000m）布一个 `segmentLen`（800m）区间
- 编队前锋 x < 区间东缘 + `leadIn`（700m）→ 开火；队尾 x < 区间西缘 - `leadOut`（700m）→ 停火
- **开火状态机防重触发**：start 条件含"队尾未越过西缘"守卫，否则编队飞过后区间会反复启停闪烁（勿删该守卫）
- 爆点位置：区间内 x 随机、z ±`zHalf`（2500m），高度 = 编队平均高度 ± `altSpread`（400m）随机
- 发射密度：`burstRate` 0.53/s + `tracerRate` 4.3/s（每激活区间）= 原跟随玩家密度（0.8/6.4）的 2/3

### 表演击落
- 编队前锋深入走廊 `killAt`（0.5）比例时，随机选一架在编轰炸机：机体周围 3 团空爆 + 直接 `_enterCrash(1~3)`
- **不走 `onEvent('killed')`** → 不计玩家积分（`_onBomberEvent` 只认 killed/damaged）
- 一次性（`_corridorKilled` 标志）；触地后走正常 despawn 移除

### 验证
`tests/python/_berlin_flak_corridor.py`：区间启停状态机 / 爆点高度带 / 击落不计分 / 飞离停火
