| pitchResp | `3.5` | 俯仰响应速率 |
| rollMax | `0.6` | 物理滚转极限 |
| rollResp | `3.0` | 滚转响应速率 |
| yawMax | `0.4` | 物理偏航极限 |

| **maxRoll** | **`0.1`** | AI 舵量限制（极小，主要平飞） |

| stallThreshold | `8` | 失速阈值 |
| il2ai | `true` | 启用 `_thinkIl2` 专属 AI |

### 高度安全（think() 全局检查与 IL-2 的关系）

| 检查 | 位置 | IL-2 是否走 | 说明 |
|------|------|------------|------|
| 撞地拉起 | `think()` agl < aglFloor(150) → pitch=1.0 | **走**（兜底保护） | IL-2 低空时满舵拉起，防撞地 |
| 高度上限俯冲 | `think()` myPos.y > patrolAltMax+100 → pitch=-0.6 | **跳过**（`!_il2State`） | IL-2 由 `_thinkIl2` 自身管理高度，避免与巡航高度冲突导致大幅俯冲-拉起循环坠毁 |

> IL-2 的高度管理：patrol 状态渐进修正到 400m（clamp maxPitch=0.15），break/retreat 高度基本不变，规避仅拉起不俯冲。

## 四、AI 状态机（`_thinkIl2`）

### 状态定义

| 状态 | 说明 |
|------|------|
| **patrol** | 固定高度 waypoint 巡逻，后炮塔开火，被攻击时规避 |
| **break** | 接敌分头：朝随机侧前 45° 方向全速飞 2-3s，同组自然散开 |
| **retreat** | 朝苏军边界 z+ 全速飞，后炮塔持续开火，被攻击时规避 |

### 状态转换

| 触发条件 | 转换 | 不可逆 |
|---------|------|--------|
| 玩家距离 < 1500m 或 被攻击 | patrol → break | 是 |
| break 持续 2-3s 结束 | break → retreat | 是 |
| killTarget 达标（4架） | WaveDirector 强制剩余 IL-2 → retreat | 是 |

### patrol 行为

| 项目 | 值 | 说明 |
|------|-----|------|
| 固定高度 | 400m | 不再定期换高度，保持固定高度平飞 |
| 高度修正除数 | 400 | `altErr / 400`，极缓修正 |
| waypoint | 半径 850m，8 点 | 绕原点巡逻 |
| waypoint 随机相位 | 是 | IL-2 加随机相位偏移，避免同组同步盘旋 |
| waypoint 推进阈值 | 250m | 距 waypoint < 250m 时推进到下一个 |
| 后炮塔开火 | 是 | 玩家在 1200m 内且在后枪 45° 锥内 |
| 被攻击规避 | 是 | 调 `_il2Evasion` |

### break 行为

| 项目 | 值 | 说明 |
|------|-----|------|
| 分头方向 | 随机左/右侧前 45° | `forward` 绕 Y 轴旋转 ±45° |
| 持续时间 | 2-3s | 到时转 retreat |
| 速度 | 全速 | throttleUp=true, throttleDown=false |
| 后炮塔开火 | 是 | break 期间仍开火 |
| 被攻击规避 | 是 | 调 `_il2Evasion` |

### retreat 行为

| 项目 | 值 | 说明 |
|------|-----|------|
| 撤退方向 | `(0, myPos.y, 20000)` | 朝苏军边界 z+ 直飞 |
| 速度 | 全速 | throttleUp=true, throttleDown=false |
| 后炮塔开火 | 是 | 持续开火（patrol/break/retreat 都开火） |
| 被攻击规避 | 是 | 调 `_il2Evasion` |

### `_il2Evasion` 规避（被攻击时）

| 概率 | 行为 | 详情 |
|------|------|------|
| **95%** | 偏航 + 加减速 | yaw ±0.5, roll 0.15, 随机加速/减速 |
| **5%** | 短暂拉起 | pitch +0.2 仅爬升调整高度（不俯冲不翻跟头，防坠毁） |

| 项目 | 值 |
|------|-----|
| 规避持续 | 1.0-1.5s |
| 规避冷却 | 2-3s |

## 六、撤退与战果判定（WaveDirector `_updateIl2Wave`）

### 撤退成功条件（不计战果）

| 条件 | 参数 | 说明 |
|------|------|------|
| 撤退中距离 > 10000m 持续 5s | `_retreatEscapeTimer > 5` | → `_despawnRequested` |
| 飞到地图边界 | `|x| 或 |z| > 14000` | 撤退中到边界 → `_retreatSuccess = true` |

### 战果计算

| 情况 | 计战果 | 机制 |
|------|--------|------|
| 被玩家击落（HP→0） | 是 | `notifyKilled` 由 GameRuntime 调 |
| 坠毁（撞地/失控） | **是** | `_updateIl2Wave` 检测 `_exploded` 调 `notifyKilled` |
| 撤退成功 | **否** | `_despawnRequested` 但不调 `notifyKilled` |

### 循环刷新逻辑

| 条件 | 动作 |
|------|------|
| 所有 IL-2 消失 且 `_il2Killed >= 4` | 波次完成 → 触发 `onWaveCleared` |
| 所有 IL-2 消失 且 `_il2Killed < 4` | 再刷一组（继续直到 4 架被击落/坠毁） |

> "所有 IL-2 消失" = 每架满足 `(_exploded && _crashTimer <= 0) || _despawnRequested`
