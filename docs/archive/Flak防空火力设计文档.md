# 防空火力（Flak）视觉系统 · 设计文档

> 第一步：**纯视觉**，不接伤害。目标：低空空域出现防空炮爆炸烟团 + 地面射来的曳光弹射击线，营造被地面防空火力覆盖的氛围。
>
> 后续扩展（接伤害、炮管闪光联动、音效）见文末「后续阶段」。

---

## 1. 模块定位

- **新建** `js/AntiAircraftFlak.js`，导出 `AntiAircraftFlak` 类
- 纯视觉，第一步不接伤害（不伤害玩家/敌机/友军）
- 关卡可配：通过 `level_xx.js` 的 `flak` 配置块启用，不配则不创建
- 由 `environment.js` 构建（与 `battlefield`/`clouds` 同级），`GameRuntime.update` 每帧调用
- 职责分离：动态天空特效归本模块，静态地面物件归 `KurskBattlefield`

## 2. 两类视觉元素

### A. flak 烟团（空爆）

- **位置**：玩家附近空域随机点，高度落在可配置的低空带（如 200-800m）
- **生命周期**（两段）：
  1. **瞬间火光**：1 个 additive 混合 Sprite，橙黄→白，0.1s 快速膨胀 + 淡出
  2. **深黑烟团**：3-5 个深灰 Sprite 错位叠加（normal 混合），膨胀 + 减速 + 淡出，持续存在时间为15秒，最大膨胀到1.5倍左右
- **纹理**：程序化生成（参考 `clouds.js` 的柔球 + blur 手法），深灰黑烟色，边缘羽化
- **对象池**：预分配 Sprite 池复用，避免每帧 new/dispose

### B. 地面曳光弹线

- **形式**：从地面发射点向天空某点射出狭长 Sprite，长边沿弹道方向对齐（复用 `weapons.js` 的弹道屏幕投影对齐思路）
- **颜色**：红 / 橙红（苏军 37mm 曳光弹偏红白）
- **生命周期**：0.1-0.2s 拖尾淡出
- **可见性**：仅当发射点在玩家视野内或一定距离内才发射（省 draw call）

## 3. 发射点来源（区域化）

> 现有 `KurskBattlefield._addAAGun` 的高炮阵地为历史遗留，不直接复用。
> 区域坐标来自 `库尔斯克地图点位.md`，点格式 `[x, z]`。

### 3.1 区域划分

| 区域 | 类型 | 高炮 |
|------|------|------|
| 友军区域（德军集结地） | friendly | **无** |
| 主战场区域 | mainBattle | 有，**基础密度 + 越靠近苏军越多**（ramp 加成） |
| 被炮击区域 | bombarded | 中等密度 |
| 苏军阵地区域 | enemy | **密集** |
| 其他（地图外兜底） | — | 中等密度（除德军阵地外都有） |

发射点为纯逻辑点（不落地面物件），在玩家周围 `activeR` 内、且**不在友军区域内**的地面随机生成。

### 3.2 高度分段（相对地面，按区域分密度权重）

| 区域 | 高度带 | 密度权重 |
|------|--------|----------|
| 非苏军（主战场/被炮击） | 500-800m | 1.0（主要区间） |
| 非苏军 | 800-1000m | 0.4（少量） |
| 非苏军 | >1000m | 0（不出现） |
| 苏军阵地 | 0-800m | 1.2（数量增加） |
| 苏军阵地 | 800-1200m | 1.0（正常） |
| 苏军阵地 | 1200-1500m | 0.35（较少） |
| 苏军阵地 | >1500m | 0（不出现） |

### 3.3 区域判定与密度

- point-in-polygon 判定玩家所在区域
- **friendly 内**：不发射（德军阵地唯一无炮）
- **enemy 内**：密度 = enemy（密集系数 1.6）
- **mainBattle 内**：密度 = mainBattleMin + (mainBattleMax − mainBattleMin) × ramp（ramp = dFriendly/(dFriendly+dEnemy)，基础 0.5 + 靠近苏军加成到 1.0）
- **bombarded 内**：密度 = bombarded（0.6）
- **都不在**：兜底密度（0.5，除德军阵地外都有）
- 烟团爆开高度：按所在区域的高度分段权重随机选段，再在段内均匀随机高度

## 4. 发射节奏

- 定时随机发射：每个发射点独立计时器，间隔 = 基础间隔 × (0.7~1.3 随机)
- 密度可配（每秒发数 / 间隔）
- flak 烟团与曳光弹线可独立配置比例（一次发射可同时产出曳光线 + 延迟在弹道终点爆开烟团，模拟"射上去再炸"）

## 5. 空间分布与性能

- flak 烟团只在玩家周围 `activeR` 半径内生成（follow 玩家，远处不生成）
- 距离剔除：超出 `cullR` 的活跃粒子立即回收
- 同时活跃数量上限（烟团 N、曳光线 M），超限丢弃新发射
- 对象池复用 Sprite + 材质（材质共享，Sprite 实例池化）
- 纹理只生成一次共享

## 6. 关卡配置（草案）

`level_03_kursk.js` 新增 `flak` 配置块（坐标来自 `库尔斯克地图点位.md`，`[x,z]`）：

```js
flak: {
  enabled: true,
  activeR: 3000,          // 玩家周围活跃半径（仅此范围内发射/生成烟团）
  cullR: 5000,            // 粒子超出此距离回收
  maxBursts: 32,          // 同时活跃烟团上限
  maxTracers: 50,         // 同时活跃曳光线上限
  burstRate: 1.2,         // 基础烟团速率（每秒，乘区域密度系数）
  tracerRate: 4.0,        // 基础曳光线速率（每秒，乘区域密度系数）

  // 区域多边形（[x,z] 点数组）
  zones: {
    friendly: [[-16501,-12152],[18864,-12152],[19274,-17485],[-16829,-17403]],
    mainBattle: [[-17403,5424],[-17157,-6761],[20874,-7458],[20587,6777],[17387,10429],[-15065,9567],[-17526,9116]],
    bombarded: [[-16788,-7434],[19151,-7188],[20956,-11824],[-17485,-11783]],
    enemy: [[-16049,5588],[18905,6039],[19807,13547],[-16788,13506]],
  },
  zoneDensity: {
    mainBattleMin: 0.5,   // 主战场基础密度（靠近友军侧）
    mainBattleMax: 1.0,   // 主战场靠近苏军侧的最大密度系数
    bombarded: 0.6,       // 被炮击区域密度
    enemy: 1.6,           // 苏军阵地密集系数
    fallback: 0.5,        // 不在任何区域时的兜底密度（除德军阵地外都有）
  },

  // 高度分段（相对地面）：每段 {alt:[min,max], weight}
  altBands: {
    nonSoviet: [          // 非苏军区域
      { alt: [500, 800],  weight: 1.0 },
      { alt: [800, 1000], weight: 0.4 },
    ],
    soviet: [             // 苏军阵地
      { alt: [0, 800],    weight: 1.2 },
      { alt: [800, 1200], weight: 1.0 },
      { alt: [1200, 1500],weight: 0.35 },
    ],
  },

  // 视觉参数（可省略用默认）
  burst: {
    smokeColor: [40, 40, 44],    // 深灰黑烟 RGB
    fireColor:   [255, 200, 120],// 火光橙黄
    smokeLife: 15,               // 烟团寿命（秒）
    smokeBlobs: [3, 5],          // 每团烟 Sprite 数
    smokeSize: [18, 32],         // 烟 Sprite 初始尺寸
    smokeMaxScale: 1.5,          // 最大膨胀倍数
    fireLife: 0.1,               // 火光寿命
  },
  tracer: {
    color: [255, 90, 60],        // 红橙
    life: [0.10, 0.20],
    len: [60, 120],              // 拖尾长度
  },
}
```

## 7. 集成点

- **`environment.js`**：
  - 构建：`if (cfg.flak?.enabled) env.flak = new AntiAircraftFlak(scene, terrain, cfg.flak)`
  - 销毁：`if (env.flak) env.flak.dispose()`
- **`GameRuntime.update`**：
  - `if (env.flak) env.flak.update(dt, this.player?.position)`
- **关卡配置**：`level_03_kursk.js` 加 `flak` 块；其他关不加即不启用

## 9. 后续阶段（不在第一步）

- **接伤害**：烟团命中玩家/敌机/友军时造成伤害（需碰撞检测，按炸点半径）
- **炮管闪光联动**：发射时让对应高炮阵地炮管闪火光（需重新设定的高炮阵地坐标落表）
- **区域感知发射点细化**：玩家进入不同区域切换不同发射点设定/密度/高度带
- **音效**：远处防空炮闷响 + 近处空爆声
- **弹道可见化**：曳光线从地面连续射向烟团炸点（弹道终点延迟爆开烟团）
