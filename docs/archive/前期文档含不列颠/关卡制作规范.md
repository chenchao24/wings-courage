# 关卡制作规范

本文档定义《勇气之翼》关卡配置的标准 schema 与制作流程。**新增关卡只加配置文件 + 注册，零代码改动**（架构见 [勇气之翼-游戏化改造.md](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/.trae/documents/勇气之翼-游戏化改造.md)）。第二关及后续关卡按此规范制作。

参考实现：[level_02_barbarossa.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/config/levels/level_02_barbarossa.js)（巴巴罗萨之鹰，6 波 9 架已跑通）。

## 一、关卡配置 schema

一个关卡 = 一个 ES 模块，`export default` 一个配置对象：

```js
export default {
  // ---- 元数据（选关卡片 + 简报用）----
  id: 'barbarossa',              // 唯一标识，用于解锁/路由
  index: 2,                      // 关卡序号（选关排序）
  name: '巴巴罗萨之鹰',           // 中文关卡名
  subtitle: 'Operation Barbarossa', // 副标题（英文/战役名）
  date: '1941.06.22',            // 历史日期（简报展示）
  cardImage: '/img/stg2.png',    // 选关卡片横幅图（见「图片资源」）
  briefing: '...',              // 任务简报文本（BriefingPage 展示）

  // ---- 解锁状态 ----
  locked: false,                 // true=未开放（卡片灰度+锁图标）

  // ---- 玩家与音乐 ----
  playerModel: '/model/bf109_opt.glb', // 玩家飞机模型
  music: '/sound/adevnAs.mp3',   // 战斗配乐（覆盖默认 combat 轨）

  // ---- 敌机总数（任务监控/结算用）----
  totalEnemies: 9,

  // ---- 波次（核心）----
  waves: [ ... ],                // 见第二节

  // ---- 对话脚本 ----
  dialogs: { ... },              // 见第三节

  // ---- 教学 ----
  tutorial: [ ... ],             // 见第四节

  // ---- 任务 ----
  mission: { ... },              // 见第五节
};
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | ✅ | 唯一标识，用于路由 `?level=xxx` 与解锁集合 |
| `index` | number | ✅ | 选关排序序号 |
| `name` / `subtitle` | string | ✅ | 卡片标题 / 副标题 |
| `date` | string | — | 历史日期，简报展示 |
| `cardImage` | string | — | 卡片横幅图路径，无则用占位 |
| `briefing` | string | ✅ | BriefingPage 简报文本 |
| `locked` | boolean | ✅ | 是否锁定 |
| `playerModel` | string | ✅ | 玩家模型 URL |
| `music` | string | — | 战斗配乐 URL，缺省用默认 combat 轨 |
| `totalEnemies` | number | ✅ | 敌机总数（= sum(wave.count)） |
| `waves` | array | ✅ | 波次数组 |
| `dialogs` | object | ✅ | 对话脚本 |
| `tutorial` | array | — | 教学步骤（缺省则跳过教学直接首波） |
| `mission` | object | ✅ | 任务定义 |

## 二、waves 波次配置

```js
waves: [
  { formation: 'solo', count: 1, entry: 'NW', label: '西北方向单机', model: '/model/i153.glb' },
  { formation: 'pair', count: 2, entry: 'S',  label: '南方双机编队', model: '/model/yak1.glb', type: 'fighter', tier: 'normal' },
  ...
],
```

### 字段说明

| 字段 | 类型 | 必填 | 默认 | 说明 |
|---|---|---|---|---|
| `formation` | string | ✅ | — | `'solo'` 单机 / `'pair'` 双机编队 |
| `count` | number | ✅ | — | 本波敌机数量 |
| `entry` | string | ✅ | — | 入场方位标识（`N/S/E/W/NW/NE/SW/SE`），供对话播报 |
| `label` | string | ✅ | — | 方位中文标签，供对话播报（如"西北方向单机"） |
| `model` | string | ✅ | 默认 yak9 | 敌机模型 URL（见可用机型表） |
| `type` | string | — | `'fighter'` | AI 类型：`fighter`/`bomber`/`transport`/`attacker`/`diveBomber` |
| `tier` | string | — | `'normal'` | 难度：`normal` / `elite` |
| `spawn` | object | — | — | 自定义出生点 `{x,y,z}`；配置后 reset() 用此位置 + `combatState='loiter'`，不再在玩家前方出生 |
| `loiter` | object | — | — | 盘旋待敌点 `{x,z,radius,alt}`；敌机飞到此点绕圈盘旋，玩家接近<1200m 切 `engaged` 接敌 |

### spawn/loiter 自定义出生行为（本关专用）

默认（无 spawn/loiter）敌机在玩家前方 1400-1900 出生、`combatState='solo'`。配置 spawn/loiter 后改为"内陆出生→飞到海边盘旋→接敌"流程，仅影响配置了此字段的波次，其他关卡无此字段时完全走原逻辑。

```js
// 不列颠关卡示例：敌机从内陆出生，飞到海边盘旋等待接敌
waves: [
  {
    formation: 'solo', count: 1, model: '/model/spitfire.glb',
    label: '海岸内陆敌机',
    spawn: { x: 0, y: 800, z: -8000 },                   // 内陆出生点（z < coastline）
    loiter: { x: 0, z: -4500, radius: 700, alt: 750 },  // 海边盘旋点 + 半径 + 高度
  },
],
```

| 字段 | 说明 |
|---|---|
| `spawn.x/y/z` | 内陆出生点世界坐标；reset() 设 `root.position` + `lookAt(loiter)` 朝海方向 |
| `loiter.x/z` | 盘旋中心点（海边）；敌机飞到此点附近绕圈 |
| `loiter.radius` | 盘旋半径（m）；绕 loiter 点画圆的半径 |
| `loiter.alt` | 盘旋高度（m）；巡逻点 y 坐标 |

**Enemy 行为**（[enemy.js _thinkLoiter](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/enemy.js#L680-L728)）：
- `combatState='loiter'`：飞向 loiter 点，到达后绕圈盘旋（8 巡逻点画圆），**不主动开火**
- 玩家距离 < 1200m → 切 `engaged` 接敌（走原 `_thinkEngaged` 逻辑）
- 无 `loiter` 配置时退化到 `solo`

**WaveDirector 处理**（[WaveDirector.js _createEnemy](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/WaveDirector.js#L192-L208)）：
- `formation==='pair'` → 复用双机互引编队逻辑（leader.wingman=wingman, combatState='formation'）
- `formation==='solo'` → `combatState='solo'`，跳过编队分支
- `_applyAiConfig(type, tier)` 在 `load()` 前注入 AI 配置（与 `_applyModelConfig` 同时机）
- 若 wave 有 `spawn`/`loiter` → 调 `e.setSpawnBehavior({spawn, loiter})`（在 load 前注入，reset 读取）；`_spawnWave` solo 分支检测 `_spawnBehavior` 时**不覆盖** `combatState`（保留 `loiter`）
- 敌机 `autoRespawn=false`，击落即移除，**不调 reset**（保留坠毁动画）

### 可用敌机机型

详见 [enemy_aircraft_specs.md](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/.trae/documents/enemy_aircraft_specs.md) 性能参数表。当前已接入：

| model URL | 机型 | 定位 | 起落架处理 | 螺旋桨处理 |
|---|---|---|---|---|
| `/model/i153.glb` | I-153 海鸥 | 教学最弱 | 自带飞行姿态 | 自带模糊盘 |
| `/model/i16.glb` | I-16 小毛驴 | 教学次弱 | 自带飞行姿态 | 自带模糊盘 |
| `/model/yak1.glb` | Yak-1 | 压力（与玩家同期） | `hideGearNodes` 隐藏 | `_propPivot` 旋转+半透明 |
| `/model/yak3.glb` | Yak-3 | 备用（最强） | `hideGearNodes` 隐藏 | `_propPivot` 旋转+半透明 |
| `/model/yak7.glb` | Yak-7 | 压力 | 自带飞行姿态 | 自带模糊盘 |
| `/model/yak9.glb` | Yak-9 | 备用 | 手动偏航 -139° | 自带模糊盘 |

**新增机型步骤**（若第二关需新模型）：
1. 把 `.glb` 放进 `model/` 目录
2. 在 [enemy.js MODEL_CONFIGS](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/enemy.js) 加配置（autoOrient/userScale；若起落架展开加 `hideGear+hideGearNodes`；若螺旋桨泛化命名加 `propNodes`）
3. 在 [enemy.js MODEL_SPECS](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/enemy.js) 加性能参数
4. 用 [tune_yak_models.html](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/tune_yak_models.html) 视觉校准朝向/缩放/起落架节点/桨叶节点

### 难度梯度设计建议

参考巴巴罗萨：教学敌（速度慢、滚转弱）→ 压力敌（接近玩家）→ 压轴（略强或 elite）。
- 第 1-3 波：I-153/I-16，`rollMax` < 玩家 2.6，让玩家易咬尾
- 第 4-5 波：Yak-1，性能接近玩家
- 第 6 波：Yak-7，可加 `tier: 'elite'` 提升压力（elite 火力 ×1.6、机动 ×1.15）

## 三、dialogs 对话脚本

由 [DialogSystem.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/DialogSystem.js) 在游戏事件触发，右上角雷达下方最多 3 条滚动。

```js
dialogs: {
  onStart:      { speaker: '指挥官', text: '...', avatar: 'commander' },
  onWaveStart: [ { speaker, text, avatar }, ... ],  // 数组：按波次索引
  onEnemyKilled:[ { speaker, text, avatar }, ... ], // 数组：轮播
  onPlayerDamaged: { speaker, text, avatar },
  onAllClear:   { speaker, text, avatar },
  onPlayerDead: { speaker, text, avatar },
},
```

### 事件触发时机（[GameRuntime.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/GameRuntime.js)）

| 事件 | 触发 | 字段类型 |
|---|---|---|
| `onStart` | 关卡开始 | 单对象 |
| `onWaveStart` | 每波开始 | **数组**（按波次索引取，`onWaveStart[0]` = 第1波） |
| `onEnemyKilled` | 每击落一架 | 数组（轮播/随机） |
| `onPlayerDamaged` | 玩家首次受击 | 单对象 |
| `onAllClear` | 全波清空 | 单对象 |
| `onPlayerDead` | 玩家阵亡 | 单对象 |

### avatar 头像映射

`avatar` 字段对应 [DialogSystem.js AVATARS](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/DialogSystem.js#L9)：

| avatarType | 头像 |
|---|---|
| `commander` | `/img/gem/commder.png`（指挥官） |
| `radio` | `/img/gem/liao.png`（通讯兵/僚机） |
| `mechanic` | SVG 占位（机械师，待补图） |
| `player` | SVG 占位（玩家，待补图） |

## 四、tutorial 教学步骤

```js
tutorial: [
  { title: '飞行控制', body: 'W/S 俯仰，A/D 滚转，Q/E 偏航...' },
  { title: '油门控制', body: 'Shift 加速，Ctrl 减速...' },
  { title: '武器系统', body: 'Space 开火...' },
  { title: '视角与暂停', body: 'C 切视角，V 观察，ESC 暂停...' },
],
```

- 4 步全屏覆盖提示框，点击"继续"下一步，最后"关闭教学"
- `onClose` 回调 → `GameRuntime` 调 `waveDirector.skipStartDelay(3)`，**3s 后开始首波**
- 教学期间允许玩家自由飞行（不冻结，预热手感）
- **缺省 tutorial**：若关卡不配 tutorial，跳过教学直接首波

## 六、新增关卡完整步骤

以新增第二关为例：

### 步骤 1：创建关卡配置文件

在 `js/config/levels/` 新建 `level_XX_<id>.js`（如 `level_01_britain.js`），按第一节 schema 填写。

### 步骤 2：注册到关卡中心

编辑 [js/config/levels/index.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/config/levels/index.js)：

```js
import britain from './level_01_britain.js';

export const LEVELS = [
  britain,                    // index 1 · 新增
  barbarossa,                 // index 2
  ...
];

const UNLOCKED_IDS = new Set(['barbarossa', 'britain']);  // 加入解锁集合
```

### 步骤 3：准备资源

- **配乐**：把 `.mp3` 放进 `sound/`，关卡 `music` 字段引用（或复用 `adevnAs.mp3`）
- **卡片图**：把横幅图放进 `img/`，关卡 `cardImage` 字段引用
- **敌机模型**：若用新机型，按第二节"新增机型步骤"接入；若复用已有模型，直接在 wave.model 引用

### 步骤 4：验证

启动服务器 `npx http-server -p 5173 -c-1 --cors`，验证：
1. 选关页新关卡卡片正常显示（横幅图、名称、解锁状态）
2. 简报页 briefing 文本展示
3. 进入关卡：教学 → 首波 → 全波按序刷新 → 全清对话 → 结算
4. 各波敌机机型/AI 类型/难度表现正确
5. 玩家死后敌机停止攻击
6. Esc 返回再进入无内存泄漏（3 次 heap 增长 <5MB）
