# 《勇气之翼》游戏化改造实现计划

## Context（背景）

当前 darkWil 是一个 Bf 109 E-4 飞行测试场（单 main.js 主循环 + 双机编队敌机 AI），需要升级为正式游戏《勇气之翼》：包含封面/菜单/选关/设置/结算完整流程，本次交付《巴巴罗萨之鹰》关卡（6 波 9 架敌机 + 教学 + 对话系统 + 任务监控 + 结算）。

**核心目标**：从工程化角度搭建可拓展的游戏框架——新增关卡只加配置文件，零代码改动；不破坏现有测试资产（座舱偏移约定 #22、坠毁物理 #25-30、编队 AI、天空/tone mapping 方案）。

**架构决策**（已与用户确认）：
- 单页应用 + ES 模块化路由 + 关卡配置驱动（非多 HTML，避免重复加载 4.4MB 模型）
- main.js 封装为 GameRuntime 模块（可 start/stop/dispose）
- 先做页面骨架（P1-P3），再整合关卡（P4+）
- 完成标准：完整跑通《巴巴罗萨之鹰》全流程

## 一、架构总览（三层分离）

```
AppShell（应用层，持有共享资源，跨关卡复用）
  ├─ renderer / scene / camera / env / clouds / audio / settings
  └─ Router（页面路由，DOM 切换）
       └─ Pages: Cover / Menu / LevelSelect / Settings / Hangar / Briefing / Result
GameRuntime（游戏层，关卡级生命周期）
  ├─ aircraft / controls / weapons / enemies[] / radar / hudCtrl
  ├─ WaveDirector（波次调度）
  ├─ DialogSystem（对话系统）
  ├─ Tutorial（教学系统）
  ├─ MissionTracker（任务监控 HUD）
  ├─ ControlsHint（按键提示）
  └─ StatsCollector（数据统计）
Config（配置层）
  └─ levels/level_02_barbarossa.js（关卡配置：waves/dialogs/tutorial/mission）
```

**资源生命周期**：
- AppShell 持有的 renderer/scene/camera/env/clouds/audio 跨关卡共享，仅刷新时销毁
- GameRuntime 持有的 aircraft/weapons/enemies/radar/hud 在 stop() 时全部释放

## 三、关键设计

### 3.1 GameRuntime（从旧 main.js 提取）

```js
class GameRuntime {
  constructor(ctx) // ctx = { renderer, scene, camera, env, clouds, audio, settings }（AppShell 注入）
  async start(levelConfig, callbacks)
  pause() / resume()
  stop()  // 释放关卡级资源
}
```

**提取映射**：
- 顶层全局变量 → `this.ctx`（共享资源）+ 实例属性（关卡级）
- `animate()` → `this._animate`（开头检查 `this._disposed`）
- `spawnFormation()` → 委托 `this.waveDirector`
- `updateCamera/updateHUD/updateCrosshair/updateIndicator` → 实例方法
- `window.__aircraft/__debug` → start 时挂载，stop 时 delete
- 旧调试 `$()` stub 保留为模块内常量

**回调接口**：`onReady / onWaveStart(i,wave) / onEnemySmoking(e) / onEnemyKilled(e,kills,total) / onAllClear(stats) / onPlayerDead(stats) / onHudUpdate(snapshot)`

**主循环关键保留**（不可破坏）：
- `dt = Math.min(clock.getDelta(), 0.05)` 限幅
- `env.sky.position.copy(camera.position)` 天空跟随
- 玩家 `autoRespawn=false`（关卡模式死则结束）
- 命中检测中冒烟通知（HP≤smokeThreshold 首次触发，用 WeakSet 防重复）

### 3.3 WaveDirector（单机/双机混合刷新）

- `wave.formation==='solo'` → `_spawnSolo()`：`new Enemy`，`combatState='solo'`，`wingman=null`（直接走 _thinkSolo，跳过编队分支）
- `wave.formation==='pair'` → `_spawnPair()`：复用旧 spawnFormation 双机互引逻辑（leader.wingman=wingman, wingman.wingman=leader, combatState='formation'）
- 敌机 `autoRespawn=false`，击落即从 `_activeEnemies` 移除，**不调用 reset**（保留坠毁动画完整性）
- `update(dt)` 检测当前波 `_exploded && _crashTimer<=0` 全满足 → 触发下一波（按 wave.delay）
- 全部波次派出且全清 → `onAllClear`
- 冒烟通知用 `WeakSet` 防重复（不在 enemy 实例上加字段，避免污染）

### 3.4 DialogSystem（右上，雷达下方）

- DOM：`.dialog-list` 容器，新条目 prepend 到顶部，最多 3 条
- `show(dialog)` 入队，超出 3 条时最早的退场动画后 remove
- 头像占位：avatar 字段映射到 SVG 剪影（cmdr/wingman/ground/player），资源到位后改 `<img>`
- 击落多条对话（数组）依次显示，间隔 800ms

### 3.5 Tutorial（4 步教学）

- 4 步提示框，点击"继续"下一步，最后"关闭教学"
- `onClose` 回调 → GameRuntime 设 10s 定时器 → 触发首波
- 教学期间允许玩家自由飞行（不冻结，预热手感）

### 3.6 Settings + GameAudio 扩展

- `Settings` 类：localStorage 持久化，`get/set/onChange`
- 默认：`{ soundEnabled:true, musicEnabled:true, hitSound:true }`
- `GameAudio` 向后兼容扩展（不改构造签名）：
  - 新增 `hitSoundEnabled / _soundDisabled` 字段
  - 新增 `setHitSoundEnabled(v) / setSoundEnabled(v) / _stopEngine()`
  - `hit()` 内加 `if(!this.hitSoundEnabled) return`
  - `fire()/explosion()/updateEngine()` 内加 `if(this._soundDisabled) return`
- AppShell 启动时同步 settings→audio，onChange 实时同步

### 3.7 UI 精致化（二战主题）

- 主题色：黄铜金 `#d4a85a`（主色）+ 羊皮纸米白 `#e8dcc0` + 警示橙 + 敌机红 + 战术蓝（HUD 数据保留）

- 卡片式选关：3×3 grid，locked 卡片灰度+锁图标+"尚未开放"，unlocked 悬停金光
- HUD 调整：
  | 位置 | 旧 | 新 |
  |---|---|---|
  | 左上 | G力/武器/击毁/血量/摄像 | **任务监控列表**（波次/进度/击落 + 血量条 + G力小字）|

## 四、不能破坏的现有约定（风险清单）

| 约定 | 位置 | 风险点 |
|---|---|---|
| `_applyCalibration()` 不动 model.position | aircraft.js:247-258 | 座舱偏移依赖（BUG #22），GameRuntime 不能改 aircraft.model.position |
| 坠毁物理 `_startCrash/_updateCrash` | aircraft.js:637-769 | WaveDirector 不调 reset 强制重生（破坏坠落动画 #25-30）|
| 编队 AI 状态机 | enemy.js:197-229 | 单机模式必须 combatState='solo' |
| 天空球跟随相机 | main.js:474 | GameRuntime 主循环必须保留 |
| dt 限幅 0.05 | main.js:380 | 必须保留 |
| 像素比 min(dpr,2) | main.js:17 | AppShell 创建 renderer 时保留 |
| 天空 toneMapped=false | environment.js:26 | 不动 |
| AudioContext 首次交互初始化 | main.js:332-335 | AppShell 在封面页"开始"按钮 click 时 init+resume |
| 窗口 resize | — | GameRuntime.stop 移除监听，radar.js 内部监听需 dispose |
| `autoRespawn` 标志 | aircraft.js:150,768 | 玩家设 false（死则结束），敌机 Enemy 构造已设 false |

**事件监听清理**：GameRuntime 内所有 addEventListener 保存引用，stop 时 removeEventListener；ensureAudio 监听由 AppShell 注册一次（不在 GameRuntime 内）。

**主循环竞态**：`_animate` 开头检查 `this._disposed`，stop 设标志 + cancelAnimationFrame。

**Three.js dispose**：Aircraft 无 dispose 方法，GameRuntime 内实现 `_disposeAircraft(ac)` 私有清理（mixer.stopAllAction + 移除粒子 + 遍历 model dispose geometry/material + scene.remove(root)）。env/clouds 由 AppShell 持有不移除。
