# 第二关《风云不列颠》轰炸机护航玩法框架

> 状态：框架定稿（2026-08-04），待后续细化与执行
> 上游：关卡制作规范.md / 第二关"风云不列颠"地图已完成（海陆 7:3、海岸线 z=-5000）
> 本文档定义第二关的核心玩法系统：轰炸机护航 + 过场动画 + 阵营 + 评级

## 一、概述与历史背景

### 玩家角色
Bf 109 E-4 战斗机，**护航战斗机**——为德国轰炸机编队护航，保护其空袭英国本土。

### 历史契合（不列颠战役 1940）
- 德国轰炸机（He 111 / Do 17 / Ju 88）从法国海岸起飞，跨越英吉利海峡空袭英国
- Bf 109 E-4 护航，受航程限制（历史痛点：油量只够海峡上空战斗 20 分钟）
- 皇家空军喷火 Mk IIa 从英国本土起飞拦截

### 阵营
| 阵营 | 单位 | 行为 |
|------|------|------|
| player | Bf 109 E-4（玩家） | 操控，击杀喷火保护轰炸机 |
| friendly | 德国轰炸机编队（NPC） | 固定航线飞行，不攻击，可被喷火攻击 |
| hostile | 喷火 Mk IIa（敌机） | 优先攻击轰炸机，玩家干扰时转火玩家 |

## 二、玩法流程（三阶段时间线）

### 阶段 0：过场伴飞表演（约 15-20s，玩家不可操控）

```
开始
  ├─ 轰炸机编队（3-4 架）从海上出生点起飞，朝岸边 -Z 方向平飞
  ├─ 玩家飞机固定在编队右后方位置，自动平飞（锁定油门、关重力、禁输入）
  ├─ 电影镜头序列（3-4 个机位）：
  │    ① 编队侧前方广角全景
  │    ② 某架轰炸机机翼旁特写
  │    ③ 海面上方低角度仰拍编队
  │    ④ 玩家座舱视角看前方编队 + 远方海平线出现黑点
  ├─ 无线电对话：开场旁白/任务简述（复用 DialogSystem）
  └─ 结束触发：远处喷火接近到 X 米 / 过场时长到
       ↓ 玩家获操控权，HUD 淡入，对话"敌机拦截！"
```

**玩家自动平飞实现**：
- Aircraft 加 `_cinematic` 标志，过场期 `enableGravity=false`、`throttle=固定值`、输入回调忽略
- 玩家飞机 `root.position` 跟随编队长机 + 固定 offset（不跑物理，直接吸附位置）
- 过场结束 `_cinematic=false`，恢复物理 + 操控，HUD 淡入

### 阶段 1：正式拦截（4 波喷火）

```
玩家获操控权
  ├─ 轰炸机编队继续按航线飞向岸边（NPC，可被喷火攻击）
  ├─ 喷火分 4 波从岸上方（z < -5000 陆地）刷新
  │    每波 2-3 架，共 8-12 架
  │    波次间隔 8-12s（让玩家喘息）
  │    第 4 波可加 1 架 elite（机动更强）做压力收尾
  ├─ 喷火目标选择：优先轰炸机，玩家干扰转火
  ├─ 玩家击杀喷火
  └─ 轰炸机飞到地图边缘消失（z < -12000 或被击落坠海）
```

### 阶段 2：结算

- **胜利**：4 波喷火全清
- **失败**：玩家阵亡（已有逻辑）
- **评级**：根据轰炸机存活数 + 玩家剩余血量 + 通关时间评 S/A/B/C（轰炸机全灭不失败，仅影响评级）

## 三、核心决策（已确认）

| 决策点 | 选定方案 | 说明 |
|--------|---------|------|
| 过场玩家飞机 | 可见 + 自动平飞 | 固定在编队侧后方，锁定物理，电影镜头切换 |
| 轰炸机模型 | 用户有模型，之后放入 | 框架先用占位（现有飞机放大改色）跑通，后续替换 |
| 喷火攻击目标 | 优先轰炸机，玩家干扰转火 | escort 护航感，不拦轰炸机就挨打 |
| 胜负条件 | 轰炸机全灭影响评级不失败 | 休闲向，强制玩家积极但不过分挫败 |

### 4.1 过场系统 CinematicController（新增）

**职责**：管理过场期间的电影镜头序列 + 玩家飞机自动平飞 + 结束触发。

**核心字段草案**：
```javascript
{
  duration: 18,              // 过场总时长（秒），结束触发兜底
  cameras: [                 // 镜头序列
    { pos: [x,y,z], lookAt: [x,y,z], t: 0,    blend: 2.0 },  // 编队全景
    { pos: [x,y,z], lookAt: [x,y,z], t: 5,    blend: 1.5 },  // 轰炸机特写
    { pos: [x,y,z], lookAt: [x,y,z], t: 10,   blend: 1.5 },  // 海面低飞
    { pos: [x,y,z], lookAt: [x,y,z], t: 14,   blend: 1.0 },  // 座舱视角看远方敌机
  ],
  playerOffset: [40, -8, 25], // 玩家飞机相对轰炸机长机的 body frame offset
  endTrigger: { type: 'distance', dist: 1500 }, // 远方喷火接近到 1500m 触发结束
  onEnd: () => {}            // 过场结束回调（交还操控权 + HUD 淡入 + 开始首波）
}
```

### 4.2 轰炸机 NPC（扩展现有 bomber）

**航线 waypoints 模式**：
- 轰炸机带固定 waypoints（海上出生 → 平飞过海 → 越过海岸线 → 飞到陆地边缘消失）
- 不做巡逻/缠斗，纯航线飞行
- 被击中 HP<20% 才轻微偏航（已有 bomber 配置）
- 被击落走 Aircraft 已有坠毁爆炸

**阵营标记**：
- Aircraft/Enemy 加 `faction` 字段，默认 'hostile'
- 轰炸机实例设 `faction='friendly'`
- 喷火目标选择 + 玩家误伤判定都读 faction

### 4.3 喷火目标选择逻辑（_thinkFighter 扩展）

```
喷火 _thinkFighter 选目标优先级：
  1. 扫描附近 friendly 轰炸机（距离 < 800m）→ 优先攻击最近的轰炸机
  2. 若玩家开火且距离玩家 < 400m，或玩家距离 < 200m → 转火玩家（自卫）
  3. 否则保持攻击轰炸机
  4. 无轰炸机可选时 → 攻击玩家
```

### 4.4 波次导演扩展（WaveDirector）

并行刷两类：
- **轰炸机编队**：1 波 3-4 架，过场开始时从海上出生，飞航线
- **喷火波**：4 波，每波 2-3 架，过场结束后从陆地方向刷新

关卡 config 字段草案：
```javascript
waves: [
  // 轰炸机编队（friendly，过场开始就刷）
  { formation: 'vic', count: 3, faction: 'friendly', type: 'bomber',
    model: '/model/he111.glb',  // 待用户放入
    route: 'sea_to_land', label: '轰炸机编队' },
  // 喷火拦截波（hostile，过场结束后分波刷）
  { formation: 'pair', count: 2, faction: 'hostile', type: 'fighter',
    model: '/model/spitfire.glb', entry: 'N', label: '喷火第1波', delay: 3 },
  { formation: 'pair', count: 2, faction: 'hostile', type: 'fighter',
    model: '/model/spitfire.glb', entry: 'N', label: '喷火第2波', delay: 12 },
  // ... 第3、4波
]
```
