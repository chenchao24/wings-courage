## 二、坐标系与地貌设计（关键决策）

### 现有坐标约定（已确认，无需改动）
- **玩家**：`aircraft.js` 硬编码 `(0, 700, 0)` + 朝 `-Z`（飞行前方 = -Z）
- **敌机**：`enemy.js` 的 `reset()` 从玩家前方 `-Z` 方向 1400-1900 单位飞来，`lookAt` 玩家
- **结论**：玩家朝 -Z = 面对岸上方向；敌机从 -Z = 岸上方向来。**坐标系完全符合需求，无需改动玩家/敌机逻辑。**

### 地貌分区（海洋:海岸 ≈ 7:3）
- 地形 `size=18000`（半宽 9000），海岸线 `z=-1000`
- **陆地（-Z 方向）**：`z ∈ [-9000, -1000]`，宽 8000，含白崖+绿色丘陵+英伦村庄
- **海洋（+Z 方向）**：`z ∈ [-1000, +9000]`，宽 10000，被 `Ocean`（size=30000）覆盖延伸至 ±15000
- 视觉上海洋辽阔无限（雾气遮盖边界），陆地一带海岸 → 接近 7:3 海峡意境
- 敌机 `z ∈ [-1900, -1400]` 在陆地上空 ✓；玩家 `z=0` 在海上 ✓

### 不列颠主题视觉参数
| 参数 | 值 | 说明 |
|---|---|---|
| 天空 topColor | `0x5a7a9a` | 灰蓝（原 `0x3a7fd6` 亮蓝） |
| 天空 midColor | `0x8090a8` | 灰蓝中段 |
| 天空 bottomColor | `0xb0b8c0` | 灰白地平线 |
| 雾色 | `0x9aa8b8` | 灰蓝雾（原 `0xc8e0f4`） |
| 雾密度 | `0.00028` | 加重 75%（原 `0.00016`）营造海峡雾气 |
| 太阳 elevation | `25°` | 低角度阴天（原 `42°`） |
| 太阳 azimuth | `150°` | 不变 |
| 太阳颜色 | `0xb0a890` | 暖灰（原 `0xffe8c0` 暖白） |

| 海洋颜色 | `0x4a6878` | 灰蓝海水 |

### 1. `js/terrain.js` — 海岸线地貌（重构）

**现有代码定位**：
- L46 `SEED = 20260731`
- L51-71 `getTerrainHeight(x, z)` 模块级导出函数（fbm 噪声）
- L80-88 `_hCache` + `getHeightCached`
- L90-208 `Terrain` 类（`create()` L97-192，`isForest` L197，`getHeight` L194）

**改动**：
1. 新增模块级 `let COAST_CONFIG = null`（在 L46 SEED 附近）
2. 新增导出函数 `setCoastConfig(cfg)` / `getCoastConfig()`：`setCoastConfig` 切换时调 `_hCache.clear()` 清空高度缓存
3. 将 L51-71 现有 `getTerrainHeight` 函数体提取为私有 `_computeLandHeight(x, z)`（原封不动）
4. 新写 `getTerrainHeight(x, z)` 顶层分发：
   - `if (!COAST_CONFIG) return _computeLandHeight(x, z)` → barbarossa 零影响
   - 海岸模式：海域 `z > coastline + transitionWidth/2` 返回 0；陆域 `z < coastline - transitionWidth/2` 返回 `_computeLandHeight + 白崖增益`；过渡带 smoothstep 插值
   - 白崖增益：`Math.sin(smoothstep(0, 400, distInland) * Math.PI) * cliffHeight`（钟形剖面，内陆深处衰减为 0）
5. `Terrain.create()`（L97-192）顶点着色分支：检测 `COAST_CONFIG`，Britain 模式海岸线附近用白垩岩色 `0xe8e4d8` + 崖顶草地 `0x7a9650` + 海滩沙色 `0xb0a888`；无 COAST_CONFIG 走原版着色
6. 新增 `Terrain.isLand(x, z)` 方法：`if (!COAST_CONFIG) return true; return z < COAST_CONFIG.coastline - 100`
7. 新增 `Terrain.dispose()` 方法：释放 mesh.geometry/mesh.material

**关键**：`_computeLandHeight` 提取后，barbarossa 关卡（COAST_CONFIG=null）行为完全不变。

## 七、假设与决策

1. **海洋:海岸 7:3 按视觉感受实现**（非精确面积）：海洋辽阔无限延伸（雾遮边界），陆地一带海岸。地形 18000 + 海洋 30000 视觉比例约 67%:33%，接近 7:3。如用户测试后要求更精确，可缩小地形 size 或调整海岸线位置。
2. **玩家/敌机位置不变**：现有坐标已满足"玩家海上面对岸上、敌机岸上来"的需求，无需改动 aircraft.js/enemy.js。
3. **向后兼容优先**：所有改动通过 `envConfig=null`/`COAST_CONFIG=null` 默认值回退，保证 barbarossa 零影响。
4. **第一波敌机用 Yak9 占位**：按用户要求，验证地图后再迭代喷火/飓风模型。
5. **不实现敌机炮塔自卫火力**：bomber/attacker 的 fire 字段保持 null stub（本次关卡仅用 fighter 类型）。
