## 一、海面雪花问题（Z-fighting 深度冲突）

### 1.1 现象

远处海面出现闪烁的雪花/噪点，最早在海边悬崖制作时就出现过，主要集中在海岸线附近和远处海面。

### 1.2 调试过程

采用逐项禁用法定位雪花来源，每步刷新页面观察：

| 测试 | 修改内容 | 结果 |
|------|---------|------|
| ① | 禁用太阳高光 `spec * 0.0` | 没变化 |
| ② | 禁用大尺度斑驳 `patchN * 0.0` | 没变化 |
| ③ | 禁用法线扰动 `detailFade = 0.0` | 没变化，面积更大 |
| ④ | 网格细分 1段→50段 | 没变化 |
| ⑤ | `depthTest: false` | **雪花消失！** 但海面挡住了飞机 |

测试⑤确认了雪花是 **深度冲突（Z-fighting）** 导致的，而非着色器噪声问题。

### 1.3 根因

```
海面 ocean:  y = 0,  transparent: true, depthWrite: false, depthTest: true (默认)
海床 terrain: y = -3 (SEA_BED)
```

- 海面与海床间距仅 **3 单位**
- 远处深度缓冲精度下降，3 单位不足以区分两者
- ocean 片元与 terrain 海床片元交替通过深度测试 → 闪烁雪花
- 海岸线附近更明显：ocean 有 alpha 渐变，terrain 有海滩(y≈2)到海床(y=-3)的过渡，高度差更小

### 1.4 最终方案

**增大海床深度**，恢复 `depthTest: true`：

| 文件 | 修改 |
|------|------|
| `js/terrain.js` L116-119 | `SEA_BED` 从 `-3` 改到 `-30`，深度间距 3→30 单位 |
| `js/ocean.js` L50-52 | 保持 `depthTest: true`（默认），删除测试用的 `depthTest: false` |

> **为什么不用 `depthTest: false`？**  
> 虽然能消除雪花，但 ocean 不再与飞机比深度，会覆盖飞机。增大海床深度是最简单安全的方案——海床被 ocean 覆盖，深度变化用户看不到。

## 二、海面波纹优化

### 2.1 问题：波纹太一致、太假

平海面模式（`waveHeight: 0`）下，波纹仅来自片元着色器的法线扰动。原实现只有两层单频 `vnoise`，且 n1 只扰动 x、n2 只扰动 z，方向性强、层次单一。

### 2.2 修改内容

**文件**：`js/ocean.js` L168-183

| 项目 | 旧方案 | 新方案 |
|------|--------|--------|
| 法线扰动 | 两层单频 `vnoise` | 两组 `fbm`（各4层叠加）+ 高频细节层 |
| x/z 对称 | n1→x, n2→z（方向对称） | 两组 fbm 用不同偏移 `(10.0, 5.0)` 分别扰动 x/z |
| 高频细节 | 无 | `fbm(vLocalPos * 0.22)` 增加细碎波纹 |
| detailFade 范围 | 600-3000m | 600-5000m（远处也保留波纹） |

**大尺度斑驳**（L198-201）：

| 项目 | 旧方案 | 新方案 |
|------|--------|--------|
| 噪声类型 | 单层 `vnoise` | `fbm`（4层叠加） |
| 对比度 | 0.92-1.08 | 0.86-1.14（增大明暗变化） |

## 三、近处方格感消除

### 3.1 问题

近处（约100m）观察海面，能看到明显的横竖直线分格感。

### 3.2 根因

`vnoise` 基于 `floor(p)` 网格 hash，所有层沿同一轴向对齐。即使 fbm 叠加多层，网格边界仍然对齐，方格感无法消除。

### 3.3 修改

**文件**：`js/ocean.js` L143-148

fbm 每层迭代加入 **旋转矩阵**，打破网格对齐：

```glsl
float fbm(vec2 p) {
  float v = 0.0; float a = 0.5;
  mat2 rot = mat2(0.80, 0.60, -0.60, 0.80);  // 旋转 36.87°
  for (int i = 0; i < 4; i++) { v += a * vnoise(p); p = rot * p * 2.0; a *= 0.5; }
  return v;
}
```

各层网格方向错开 → 方格边界不再对齐 → 横竖直线感消失。

高频细节层也从 `vnoise` 改为 `fbm`，同样经过旋转去方格。

## 五、海面距离雾调淡

### 5.1 问题

高空300m以上看海面偏白偏浅，低空看海面偏深。

### 5.2 根因

ocean 有 **独立距离雾**，不受场景雾控制：

```js
// environment.js L200-201
fogDensity: cfg.ocean?.fogDensity ?? 0.0003,  // 默认 0.0003
```

level 配置中未设置 `ocean.fogDensity`，使用默认值 0.0003。高空看远处海面 dist 大，雾混合比例高（3000m 处约 59%），大片海面被雾色 `0xb8c4d0`（浅灰蓝）混合 → 偏白。

### 5.3 修改

**文件**：`js/config/levels/level_01_britain.js` L168

```js
fogDensity: 0.00012,  // 默认0.0003太浓，高空海面过白；调淡保留海天衔接
```

| dist | 旧值 0.0003 | 新值 0.00012 |
|------|------------|--------------|
| 1000m | 26% 雾混合 | 11% |
| 3000m | 59% | 30% |
| 5000m | 78% | 45% |

## 六、天空远景云系统

### 6.1 背景

天空球 shader 中已有一套远景云系统，但被 `enabled: false` 关闭（注释"效果不佳已关闭"）。

### 6.2 改进内容

**文件**：`js/environment.js`

#### 6.2.1 fbm 加旋转矩阵（L101-106）

与 ocean 相同的方案，每层旋转 36.87° 打破网格对齐，消除方格感。

#### 6.2.2 三层云系统（L117-160）

| 层 | 位置 | 频率 | 密度 | 颜色特点 | 作用 |
|---|------|------|------|---------|------|
| 远景层云 | 地平线（dir.y<0.35） | 低频拉伸 | 最密 85% | 偏暗（大气透视 ×0.75） | 远处厚重云幕墙 |
| 中空层积云 | 中等高度（0.06-0.75） | 中频 | 中等 80% | 标准色 | 主要云层，视觉主体 |
| 高空卷云 | 高处（0.25-0.95） | 高频 | 稀疏 50% | 偏亮（×1.15） | 点缀，天空层次感 |

- 三层各有独立偏移（7.3 / 15.7），纹理不重复
- 漂移速度不同，避免同步移动
- 太阳染色：朝阳侧暖白、背阳侧灰

#### 6.2.3 修复瀑布纹（L126-128）

**问题**：原方案 `hf = 1.0 / max(abs(dir.y), 0.12)` 在地平线方向可达 8.3，导致 fbm 采样坐标过大，hash 函数精度下降产生伪随机条纹，形成"瀑布状幕墙"。

**修改**：改为 `smoothstep` 平滑拉伸：

```glsl
// 旧：float hf = 1.0 / max(abs(dir.y), 0.12);  // 急剧变化 + 大坐标
// 新：
float stretch = mix(3.5, 1.0, smoothstep(0.0, 0.25, dir.y));  // 平滑过渡
vec2 cuv = dir.xz * stretch * 0.8;
```

| 旧方案 | 新方案 |
|--------|--------|
| 最大拉伸 8.3×，采样坐标 2.9+ | 最大拉伸 3.5×，采样坐标 2.8 |
| dir.y 微小变化 → hf 急剧跳变 → 条纹 | smoothstep 平滑过渡 |

#### 6.2.4 修复航向方向缺云（L127, L130）

**问题**：正前方航向方向看不到远景云。

**根因**：`dir.xz * stretch * 0.4` 在地平线方向最大采样半径仅 1.4，fbm 在小范围内可能整个航向方向落在低值区。

**修改**：
- 采样系数 `0.4` → `0.8`（采样半径翻倍，分布更均匀）
- 阈值 `coverage × 1.0` → `coverage × 1.15`（下阈值降低，更多区域有云）

#### 6.2.5 增大中空/高空云密度（L138-159）

陆地方向地平线被地形遮挡，只能看到中高空。增大中空和高空云的密度与范围：

| 参数 | 中空层积云 | 高空卷云 |
|------|-----------|---------|
| 仰角范围 | 0.08-0.65 → 0.06-0.75 | 0.30-0.92 → 0.25-0.95 |
| 覆盖度系数 | ×0.75 → ×0.9 | 固定阈值降低 |
| 不透明度 | 0.75 → 0.80 | 0.40 → 0.50 |

### 6.3 level 配置

## 九、关键技术要点

### 9.1 Z-fighting（深度冲突）

当两个面间距太小（<10单位）且 far plane 较远（>10000）时，远处深度缓冲精度不足，导致面片交替显示闪烁。解决方案：增大面间距或使用 `polygonOffset`。

### 9.2 Value Noise 方格感

基于 `floor(p)` 网格 hash 的 value noise，所有层沿同一轴向对齐，fbm 叠加也无法消除方格感。解决方案：fbm 每层旋转坐标（`mat2` 旋转矩阵），打破网格对齐。

### 9.3 Hash 精度条纹

`fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453)` 在 `p` 值过大时（>100），`sin` 计算精度下降，产生伪随机条纹/噪点。解决方案：限制采样坐标范围，或用 `mod` 取模。

### 9.4 1/dir.y 投影畸变

天空球云用 `1/dir.y` 做地平线拉伸时，dir.y 微小变化导致拉伸系数急剧跳变，产生瀑布纹。解决方案：改用 `smoothstep` 平滑过渡的拉伸系数。
