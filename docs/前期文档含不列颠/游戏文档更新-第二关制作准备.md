#### 新增章节「八、螺旋桨固定旋转系统」

位置:在现有第七节「视角键位约定」之后追加。

内容要点:
- **背景**:Yak-1/Yak-3 桨叶节点泛化命名(Line16-FACES_1 等),PROP_KEYWORDS(prop/螺旋桨/vint/винт...)匹配不到,propBranches.blur 为空导致螺旋桨不可见
- **实现位置**:[aircraft.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/aircraft.js)
- **核心机制**:
  1. `MODEL_CONFIGS.propNodes` 显式声明桨叶节点(Yak-1: Line16/Line17/Line05;Yak-3: Line30/Line29/Line05,各 3 片)
  2. `_applyPropNodes()`:把桨叶加入 `propBranches.blur` 并 `_applyPropMode()` 让其可见
  3. `_setupPropPivot()`:算 3 片桨叶世界质心作桨毂位置(对称分布时质心≈桨毂轴心),创建 `THREE.Group` pivot 挂到 model 下,用 `Group.attach` 把桨叶 reparent(保持世界变换),旋转 pivot 时 3 片桨叶绕桨毂同步转
  4. `update()` 每帧:`if (this._propPivot && !this.crashed) this._propPivot.rotateZ(PROP_SPIN * dt)`
  5. 常量 `PROP_SPIN = 60`(rad/s,约 9.5 圈/s)— **固定转速不随油门**(敌机远距离观看,呈现高速模糊感即可)
  6. 桨叶材质半透明 `opacity = 0.6`:高速旋转多帧视觉暂留叠加成模糊圆盘
- **频闪(wagon-wheel)规避**:3 片桨叶间隔 120°,60fps 下每帧转角 = PROP_SPIN/60。60 rad/s → 57°/帧,接近 60° 频闪临界但半透明掩盖。**切勿提到 62.8 rad/s**(60°/帧临界点,桨叶看起来倒转/抖动);也不要取 125.6 rad/s(120°/帧,桨叶每帧回到原位看似静止)
- **坠毁停转**:`!this.crashed` 保护,坠毁后桨叶停转(更真实,模型随后爆炸隐藏)
- **适用范围**:仅 Yak-1 / Yak-3(配置了 `_propNodes`);其他机型对比表:

| 机型 | 螺旋桨方案 |
|---|---|
| Bf 109(玩家) | 螺旋桨动画轨道,`propAction` 由 `mixer.update` 推进旋转 |
| I-153 / I-16 | 模型自带预制模糊盘贴图,静态显示 |
| Yak-7 | 模型自带模糊盘(未配 propNodes),静态显示 |
| Yak-9 | 模型自带模糊盘,静态显示 |
| **Yak-1 / Yak-3** | **`_propPivot` 固定旋转 + 半透明**(本次新增) |

#### 新增章节「九、多敌机模型扩展机制」

位置:在螺旋桨章节之后追加。

内容要点:
- **背景**:不同机型需要差异化的外观(朝向/缩放/起落架/螺旋桨)和性能(速度/机动/HP),通过注册表按 URL 注入
- **三个注册表**([enemy.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/enemy.js)):
  1. `MODEL_CONFIGS`(外观):autoOrient/yawOffset/pitchOffset/rollOffset/userScale/muzzleOffsets/hideGear/hideGearNodes/propNodes
  2. `MODEL_SPECS`(性能):maxSpeed/cruiseSpeed/maxHp/pitchMax/pitchResp/rollMax/rollResp/yawMax/yawResp/stallThreshold/liftK
  3. `TIER_CONFIGS`(难度乘数):normal/elite(maxSpeed/agility/hp 乘数)
- **注入顺序**(`_createEnemy` 中):
  ```
  new Enemy() → 构造函数调默认 _applyAiConfig('fighter','normal')
  e._applyAiConfig(type, tier) → AI_TYPE_CONFIGS × TIER_CONFIGS(类型基线)
  e.load(url) → 内部 _applyModelConfig(url)
                ├─ MODEL_CONFIGS:外观覆盖(含 hideGear 标志 + hideGearNodes + propNodes)
                └─ MODEL_SPECS:性能覆盖(读 this.aiTier 施加 tier 乘数)
              → super.load() 内部加载模型
                └─ 若 hideGear=true → _hideLandingGear()
                └─ 若 propNodes → _applyPropNodes() → _setupPropPivot()
              → reset()(hp = maxHp)
  ```
- **优先级**:MODEL_SPECS(机型特定)> AI_TYPE_CONFIGS(类型基线)> 构造函数默认值
- **起落架隐藏** `_hideLandingGear()`([aircraft.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/aircraft.js)):优先用显式 `hideGearNodes` 列表精准匹配隐藏,退化才用 `GEAR_KEYWORDS`(向后兼容 I-153/I-16)
- **螺旋桨节点** `_applyPropNodes()`:把 MODEL_CONFIGS.propNodes 加入 propBranches.blur,并触发 _setupPropPivot
- **自动朝向** `_autoOrient()`:优先用 `_propNodes` 显式列表收集桨叶节点算质心,退化才用 `PROP_KEYWORDS`。算法:质心 (cx, cz) → `phi = atan2(cx, cz)` → `yawOffset = radToDeg(π - phi)`,对齐机头到 -Z(飞行前方)
- **当前已接入机型表**:I-153 / I-16 / Yak-1 / Yak-3 / Yak-7 / Yak-9(详见 [enemy_aircraft_specs.md](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/.trae/documents/enemy_aircraft_specs.md) 性能参数表)
- **新增机型步骤**:见关卡制作规范第二节
