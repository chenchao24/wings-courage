## 一、威胁警告系统

由 [GameRuntime.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/GameRuntime.js) 驱动，含两类警告，均已 Playwright 验证（`test_shots/test_lock_altitude.py`，截图 `test_shots/10_low_altitude.png` / `11_lock_warning.png`）。

### 1.1 低空警告（AGL < 200m）

**触发条件**：玩家离地高度 AGL < 200m。

**实现链路**：
- `GameRuntime._updateHud()` 计算 `AGL = player.root.position.y - terrain.getHeight(x, z)`（地形未注入时按 0 处理，[GameRuntime.js:655-669](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/GameRuntime.js#L655-L669)）
- HUD 快照置 `lowAltitude: agl < 200`
- [HudController.js:117](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/HudController.js#L117)：`e.altitude.classList.toggle('show', !!snap.lowAltitude && !snap.crashed)` — 仅未坠毁时显示
- [hud-template.js:35](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/hud-template.js#L35)：`<div id="hud-altitude">高度过低 注意拉起</div>` 屏幕中央
- [Theme.js:528](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/app/Theme.js#L528)：`#hud-altitude.show { animation: stallBlink 0.45s steps(2) infinite }` 红色闪烁

**注意**：玩家初始高度 700m，需俯冲接近地面（y<200m 或地形高度附近）才会触发，非 bug。

### 1.2 后方锁定警告

**触发条件**：敌机位于玩家后方锥 + 机头朝向玩家 + 距离 < 700m。

**判定**（[GameRuntime.js _updateLockWarning](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/GameRuntime.js#L554-L581)，冷却字段 `_lockWarnCd` 定义在 [GameRuntime.js:89](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/GameRuntime.js#L89)）：
- 后方锥：`玩家前向 · (玩家→敌机) < -0.1`（敌机在玩家后方 90° 锥内）
- 敌机机头朝向玩家：`enemy.getForward() · (敌机→玩家) > 0.95`（约 18° 射击锥）
- 距离 < 700m

**表现**：触发僚机无线电对话「我们被锁定了，小心规避！」（speaker=僚机，avatar=radio），**10s 冷却**（`_lockWarnCd = 10`）避免刷屏。

## 二、音量调节系统

[audio.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/audio.js) 实现 4 条独立音量总线，设置页 [SettingsPage.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/app/pages/SettingsPage.js) 提供 4 个滑块 + 4 个试听按钮（边调边听）。

### 2.1 音量总线结构

在 `GameAudio.init()` 创建（[audio.js:64-73](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/audio.js#L64-L73)）：

```
ctx.destination
  ↑
master (0.55)              ← 总音量/静音
  ↑
  ├─ _engineBus  → 引擎节点（锯齿+三角+噪声）
  ├─ _gunBus     → 机枪节点（噪声 burst + sine thump）
  ├─ _sfxBus     → 音效节点（命中 ping / 爆炸）
  └─ _musicGain  → 背景音乐（每轨独立，支持交叉淡入淡出）
```

### 2.2 映射与默认值

- 滑块 0-100 → 增益 0-2.0 线性映射，**50 = 1.0（基准）**
- 默认值（[Settings.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/game/Settings.js) 默认配置）：

| 总线 | 默认滑块值 | 说明 |
|---|---|---|
| 音乐 music | 90 | 偏高，营造氛围 |
| 音效 sfx | 25 | 偏低，避免命中 ping 刺耳 |
| 引擎 engine | 35 | 偏低，持续背景音不喧宾夺主 |
| 机枪 gun | 50 | 基准 |

**注意**：`audio.js` 构造函数内 `_engineVolume/_gunVolume/_sfxVolume` 初始为 1.0（即 slider 50%），实际运行值由 `Settings` 同步覆盖。**已存档浏览器的 localStorage（`couragewings_settings_v1`）会覆盖新默认值**——用户需清 localStorage 或手动调滑块才能应用新默认。

### 2.3 试听按钮

设置页 4 个试听按钮，点击立即播放对应总线的一段预览音（`_previewTimers` 管理定时器），实现"边调边听"。

### 2.4 设置方法

`setMusicVolume(v)` / `setEngineVolume(v)` 等（[audio.js:349+](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/audio.js#L349)）：实时调对应总线 gain，`Settings.set` → `audio.set*Volume` 实时同步（无需重启）。

## 八、螺旋桨固定旋转系统

由 [aircraft.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/aircraft.js) 实现。仅 Yak-1 / Yak-3 走此路径（配置了 `_propNodes`），其他机型不受影响。

### 8.1 背景

Yak-1 / Yak-3 模型的桨叶节点是泛化命名（`Line16-FACES_1` 等），`PROP_KEYWORDS`（prop/螺旋桨/airscrew/propeller/vint/винт...）一个都匹配不到，导致 `propBranches.blur` 为空 → **螺旋桨完全不可见**。且模型无螺旋桨动画轨道，无法走 Bf 109 的 `propAction` 动画路径。

### 8.2 核心机制

1. **`MODEL_CONFIGS.propNodes` 显式声明桨叶节点**（[enemy.js MODEL_CONFIGS](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/enemy.js)）
   - Yak-1：`Line16-FACES_1`, `Line17-FACES_1`, `Line05-FACES_1`（3 片）
   - Yak-3：`Line30-FACES_1`, `Line29-FACES_1`, `Line05-FACES_1`（3 片）

2. **`_applyPropNodes()`**：把桨叶加入 `propBranches.blur` 并 `_applyPropMode()` 让其可见

3. **`_setupPropPivot()`**（[aircraft.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/aircraft.js)）：算 3 片桨叶世界质心作桨毂位置（3 片对称分布时质心 ≈ 桨毂轴心），创建 `THREE.Group` pivot 挂到 model 下，用 `Group.attach` 把 3 片桨叶 reparent 进去（保持世界变换不变）。这样旋转 pivot 时 3 片桨叶绕桨毂**同步**转，而非各自绕自身原点翻滚

4. **`update()` 每帧**（[aircraft.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/aircraft.js)）：
   ```js
   if (this._propPivot && !this.crashed) this._propPivot.rotateZ(PROP_SPIN * dt);
   ```

5. **常量 `PROP_SPIN = 60`**（rad/s，约 9.5 圈/s）— **固定转速不随油门**（敌机远距离观看，呈现高速模糊感即可）

6. **桨叶材质半透明 `opacity = 0.6`**：高速旋转多帧视觉暂留叠加成模糊圆盘

### 8.3 频闪（wagon-wheel）规避

3 片桨叶间隔 120°，60fps 下每帧转角 = `PROP_SPIN / 60`。
- `60 rad/s` → `57°/帧`，接近 60° 频闪临界但半透明掩盖
- **切勿提到 62.8 rad/s**（60°/帧临界点，桨叶看起来倒转/抖动）
- 也不要取 `125.6 rad/s`（120°/帧，桨叶每帧回到原位看似静止）

### 8.4 坠毁停转

`!this.crashed` 保护，坠毁后桨叶停转（更真实，模型随后爆炸隐藏）。

### 8.5 各机型螺旋桨方案对比

| 机型 | 螺旋桨方案 |
|---|---|
| Bf 109（玩家） | 螺旋桨动画轨道，`propAction` 由 `mixer.update` 推进旋转 |
| I-153 / I-16 | 模型自带预制模糊盘贴图，静态显示 |
| Yak-7 | 模型自带模糊盘（未配 propNodes），静态显示 |
| Yak-9 | 模型自带模糊盘，静态显示 |
| **Yak-1 / Yak-3** | **`_propPivot` 固定旋转 + 半透明**（本系统） |

| 工具 | 路径 | 用途 |
|---|---|---|

## 九、多敌机模型扩展机制

通过三个注册表按模型 URL 注入外观与性能，实现机型差异化。核心代码在 [enemy.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/enemy.js) 与 [aircraft.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/aircraft.js)。

### 9.1 三个注册表

1. **`MODEL_CONFIGS`**（外观，[enemy.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/enemy.js)）：按模型 URL 注入
   - `autoOrient` / `yawOffset` / `pitchOffset` / `rollOffset`：朝向校准
   - `userScale`：外观缩放（公式 `3.6 × 真实最长维 / 9.92`，Bf 109 翼展基准）
   - `muzzleOffsets`：枪口位置
   - `hideGear` + `hideGearNodes`：起落架隐藏标志 + 显式节点列表
   - `propNodes`：显式螺旋桨桨叶节点列表

2. **`MODEL_SPECS`**（性能，[enemy.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/enemy.js)）：按模型 URL 注入飞行性能
   - `maxSpeed` / `cruiseSpeed`：最大速度 / 巡航速度
   - `maxHp`：最大血量
   - `pitchMax` / `pitchResp`：俯仰角速度上限 / 响应
   - `rollMax` / `rollResp`：滚转角速度上限 / 响应
   - `yawMax` / `yawResp`：偏航角速度上限 / 响应
   - `stallThreshold` / `liftK`：失速阈值 / 升力系数

3. **`TIER_CONFIGS`**（难度乘数，[enemy.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/enemy.js)）：`normal` / `elite`
   - `maxSpeed` / `agility` / `hp` 三个乘数

### 9.2 注入顺序（`_createEnemy` 中）

```
new Enemy()                          → 构造函数调默认 _applyAiConfig('fighter','normal')
e._applyAiConfig(type, tier)        → AI_TYPE_CONFIGS × TIER_CONFIGS（类型基线）
e.load(url)                         → 内部 _applyModelConfig(url)
                                      ├─ MODEL_CONFIGS：外观覆盖（含 hideGear 标志 + hideGearNodes + propNodes）
                                      └─ MODEL_SPECS：性能覆盖（读 this.aiTier 施加 tier 乘数）
                                    → super.load() 内部加载模型
                                      └─ 若 hideGear=true → _hideLandingGear()
                                      └─ 若 propNodes    → _applyPropNodes() → _setupPropPivot()
                                    → reset()（hp = maxHp）
```

**优先级**：`MODEL_SPECS`（机型特定）> `AI_TYPE_CONFIGS`（类型基线）> 构造函数默认值。

### 9.3 起落架隐藏 `_hideLandingGear()`

实现位置：[aircraft.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/aircraft.js)。

- 优先用显式 `hideGearNodes` 列表精准匹配节点名隐藏（Yak-1 / Yak-3 各 22 个节点，用户用 [tune_yak_models.html](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/tune_yak_models.html) 视觉识别）
- 退化才用 `GEAR_KEYWORDS`（gear/landing/wheel/起落架/轮）关键词匹配（向后兼容 I-153 / I-16 等历史机型）
- 玩家 Bf 109 不设 `_hideGear`，起落架保持模型默认状态（飞行姿态收起）

### 9.4 螺旋桨节点 `_applyPropNodes()`

把 `MODEL_CONFIGS.propNodes` 加入 `propBranches.blur` 分支，并触发 `_setupPropPivot()`（详见第八节）。仅 Yak-1 / Yak-3 走此路径。

### 9.5 自动朝向 `_autoOrient()`

实现位置：[aircraft.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/aircraft.js)。

- **优先用 `_propNodes` 显式列表**收集桨叶节点算质心，确定机头方向
- 退化才用 `PROP_KEYWORDS` 关键词匹配
- **算法**：质心 (cx, cz) → `phi = atan2(cx, cz)` → `yawOffset = radToDeg(π - phi)`，对齐机头到 -Z（飞行前方）
- 验证：4.6 圈旋转测试 `quatChanged=true`，桨叶世界 quaternion 角度变化与 pivot 一致

### 9.6 当前已接入机型

详见 [enemy_aircraft_specs.md](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/.trae/documents/enemy_aircraft_specs.md) 性能参数表：

| model URL | 机型 | 起落架处理 | 螺旋桨处理 |
|---|---|---|---|
| `/model/i153.glb` | I-153 海鸥 | 自带飞行姿态 | 自带模糊盘 |
| `/model/i16.glb` | I-16 小毛驴 | 自带飞行姿态 | 自带模糊盘 |

## 十一、场景渲染系统（海洋/地形/环境）

### 11.1 海洋渲染（[ocean.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/ocean.js)）

Gerstner 五重波 GPU 顶点位移 + Fresnel 天空反射 + Blinn-Phong 太阳高光 + fbm 泡沫 + 距离雾融入海平线。

| 参数 | 位置 | 说明 |
|---|---|---|
| `waveHeight` | 关卡 `ocean` 配置 | Gerstner 波振幅系数；**0=平海面**（不列颠关卡设 0 去海浪） |
| `fresnel` | ocean.js 片元着色器 | `0.02 + 0.45 * pow(...)`（系数从 0.98 降到 0.45，降低天空反射去塑料感） |
| `spec` | ocean.js 片元着色器 | 太阳高光强度 0.9→0.3（降低镜面反光） |
| `uFogDensity` | ocean.js 独立雾 | 海平线距离雾（不受场景雾影响），陆地清晰同时海洋融入天空 |
| `coastAlpha` | ocean.js 片元着色器 | 海岸线 alpha 渐变（coastline-30→coastline+220 软过渡沙滩） |
| `edgeFade` | ocean.js 片元着色器 | 边缘 alpha 渐隐（最后 5000m 从 1→0），避免海面跟随相机时露出背景 |

### 11.2 地形各向异性 blur（[terrain.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/terrain.js)）

**问题**：基于 `vWorldPos.z` 的过渡带在海岸线斜度大时（等高线接近 x 方向），垂直等高线方向投影 = `blur * cos(α)` 趋近 0，过渡带"消失"，白色↔草地交界锯齿明显。

**修复**：在 `MeshStandardMaterial.onBeforeCompile` 注入的片元着色器中，用海岸线斜率归一化 blur：

```glsl
float slope = cos(vWorldPos.x * 0.0006) * 0.72
            + cos(vWorldPos.x * 0.0017 + 2.1) * 0.85
            + cos(vWorldPos.x * 0.0041 + 4.3) * 0.82;  // d(coastLineAt)/dx
float normFactor = sqrt(1.0 + slope * slope);
float blur = 38.0 * normFactor;  // 垂直等高线方向恒定 38m 过渡
```

效果：斜度小处 z 方向 blur 38m；斜度大处（normFactor≈2.59）z 方向 blur 放大到 ~98m，但垂直等高线方向恒定 38m，消除斜度大处的锯齿。

### 11.3 天边云带默认关闭（[environment.js](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/environment.js)）

天空 shader 内 fbm 噪声绘制的远景云带（零 draw call，无穷远海平线层云）。

- **默认关闭**：`cloudEnabled = skyClouds.enabled === true`（需显式 `enabled: true` 才开启）
- 关卡配置 `skyClouds: { enabled: false }` 显式关闭；无配置时默认关闭
- 不列颠/巴巴罗萨两关均无天边云带

### 11.4 海岸线弯曲（[terrain.js coastLineAt](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/terrain.js#L108-L114)）

三层正弦波在 x 方向产生海湾/海岬（±1900m 起伏），JS 端（terrain 高度/着色）与 ocean.js GLSL 端（discard）共用同一公式：

```js
coastline + sin(x*0.0006)*1200 + sin(x*0.0017+2.1)*500 + sin(x*0.0041+4.3)*200
```

正弦波不用 hash 噪声——避免 JS double 与 GLSL highp float 在 `fract(sin*large)` 上的精度不匹配。
