# 第二关「风云不列颠」护航模式交接文档

> **创建时间**：2026-08-05
> **会话目标**：实现第二关轰炸机护航玩法 —— 4 架喷火式敌机以双机编队出生，优先攻击轰炸机（表演性质），被玩家攻击或近距离时转而攻击玩家，轰炸机自卫炮塔还击。
> **当前状态**：基础逻辑已实现，待实际游戏测试调校。

---

## 一、玩法设计概述

### 1.1 关卡背景
- 1940 年 9 月 15 日不列颠战役，玩家驾驶 Bf 109 E-4 从法国海岸起飞
- 护航 Ju 88 轰炸机编队（3 架 V 字编队）穿越英吉利海峡
- 4 架英国皇家空军喷火式战斗机从内陆方向拦截

### 1.2 核心交互逻辑
```
玩家(300m内接近/开火) ──→ 敌机切engaged攻击玩家
玩家(拉开>1200m) ──────→ 敌机切回attackBomber攻击轰炸机
```

### 1.3 表演性质约定
- **敌机 vs 轰炸机互射为纯表演**：不判断命中、不掉血、不击落
- 敌机子弹不会命中轰炸机（GameRuntime 命中检测跳过）
- 轰炸机炮塔子弹不会命中敌机（damageMin=0/damageMax=0 + 命中检测跳过）
- 目的：减轻程序负担，仅做视觉效果

### 2.2 敌机 AI
#### `js/enemy.js`
- **新增临时向量**（L18-19）：`_bomberTarget`、`_bomberFwd`
- **新增状态属性**（构造函数）：
  - `_bomberTargets`：友军轰炸机列表（GameRuntime 注入）
  - `_lastPlayerAttackTime`：被玩家攻击时间戳
  - `_attackSlot`：攻击方向槽位（top/front/left/right）
  - `_attackPhase`：攻击阶段（approach/strike/egress）
- **`takeDamage()` 修改**：被玩家攻击时切 `engaged` 状态
- **`_thinkEngaged()` 修改**：玩家距离 > 1200m 切回 `attackBomber`（替代原 10s 计时）
- **新增 `_thinkAttackBomber()`**（约 L1059-1191）：
  - 玩家接近 < 300m → 切 engaged
  - 4 方向槽位攻击占位（top=前上方俯冲/front=前方迎头/left=左侧/right=右侧）
  - 三阶段循环：approach（接近）→ strike（开火）→ egress（脱离）→ approach
  - strike 阶段：距轰炸机 < 1000m 朝轰炸机开火，< 250m 切 egress
  - egress 阶段：全速脱离，距轰炸机 > 1200m 切回 approach

### 2.3 友军轰炸机
#### `js/game/FriendlyBomber.js`
- **`_applyModelConfig()` 修复**：补上 `muzzleOffsets` 和 `muzzleDirs` 注入（原遗漏导致炮塔不开火）
- **`_cruiseSpeed`**：55 → 45（与玩家速度同步）
- **新增 `_wobblePhase`**：僚机摇摆随机相位
- **`_updateWingman()` 增强**：
  - 上下浮动：0.4Hz，幅度 ±3m
  - Roll 摇摆：0.3Hz，幅度 ±2°
- **`_turretFire()` 重写**：
  - 距离 500-1000m（原 1500m）
  - 敌机必须在轰炸机后方（body frame z>0，前枪不参与）
  - 连发 1.5-2s + 冷却 3-5s

### 2.4 武器系统
#### `js/weapons.js`
- **轰炸机子弹颜色**：`0xff7a3a` → `0xff5028`（橙红，与战斗机金色区分）
- **枪口闪光增强**：
  - 尺寸 1.3-1.8 → 3.2-4.2（约 2.5 倍）
  - 持续时间 0.05s → 0.12s（约 2.4 倍）
  - 淡出曲线：前 60% 保持满亮度，后 40% 快速淡出

### 2.5 波次导演
#### `js/game/WaveDirector.js`
- **新增 `double-pair` 编队类型**：2 个双机编队，第二组偏移到第一组侧后方
- **`_spawnWave()` 修复**：`pairOffset` 普通对象用 `new THREE.Vector3()` 包装后调用 `.clone()`
- **`target` 计数**：支持 `double-pair` 类型（count=4）

### 2.6 游戏运行时
#### `js/game/GameRuntime.js`

  - 分配攻击方向槽位 `['top', 'front', 'left', 'right']`
- **`onWaveSpawned` 回调**：刷怪后调用 `_injectBomberTargets()`
- **主循环新增**：调用 `hud.updateBomberIndicator()` 绘制长机识别框

## 三、核心架构

### 3.1 状态机流转
```
                    ┌─────────────────────────────────────┐
                    ↓                                     │
              ┌──────────┐                          ┌──────────┐
              │formation │ ──3s──→                  │attackBomber│
              └──────────┘                          └──────────┘
                                                         │
                                          ┌──────────────┼──────────────┐
                                          ↓              ↓              ↓
                                     玩家接近<300m   玩家开火      无触发
                                          │              │              │
                                          └──────┬───────┘              │
                                                 ↓                      │
                                            ┌──────────┐                │
                                            │ engaged  │                │
                                            └──────────┘                │
                                                 │                      │
                                          玩家拉开>1200m                │
                                                 └──────────────────────┘
```

### 3.2 攻击轰炸机三阶段循环
```
approach（接近占位点）
    ↓ 距轰炸机 < 1000m
strike（俯冲开火）
    ↓ 距轰炸机 < 250m
egress（全速脱离）
    ↓ 距轰炸机 > 1200m
approach（循环）
```

### 3.3 4 方向攻击槽位
| 槽位 | 占位坐标（相对轰炸机） | 攻击方式 |
|------|------------------------|----------|
| `top` | 前方 400m + 上方 400m | 前上方俯冲 |
| `front` | 前方 600m + 上方 150m | 前方迎头攻击 |
| `left` | 左侧 500m + 略前 100m | 侧向扫射 |
| `right` | 右侧 500m + 略前 100m | 侧向扫射 |

### 3.4 轰炸机自卫炮塔逻辑
```
敌机位于轰炸机后方 500-1000m？
    ├─ 是 → 周期性开火（连发 1.5-2s + 冷却 3-5s）
    └─ 否 → 不开火（前枪不参与，正面不生效）
```

判断方法：敌机位置转换到轰炸机 body frame，`z > 0` 表示在后方。
