# 第二关《风云不列颠》地图制作计划

## Context（背景）

用户要制作第二关《风云不列颠》(Battle of Britain, 1940)的地图。需求:
- 英吉利海峡地貌:一侧大海(无限延伸),一侧英国海岸,海洋:海岸 ≈ 7:3
- 玩家飞机刷新在海上,面对岸上方向
- 敌机来自岸上方向(英国一侧)
- 海水和天空渲染要符合英吉利海峡特点(灰蓝、雾气重、多阴天)
- 英军第一波用 Yak9 占位(验证地图后再迭代喷火/飓风)

**关键发现(基于代码探索)**:
- 玩家在 [aircraft.js:1062](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/aircraft.js#L1062) 硬编码 `(0, 700, 0)` + 朝 `-Z`
- 敌机在 [enemy.js:515-523](file:///c:/Users/CC/Desktop/gameSpace727/darkWil/js/enemy.js#L515-L523) 的 `reset()` 中从**玩家前方(-Z 方向)**1400-1900 单位飞来,`lookAt` 玩家
- **这正好符合需求**:玩家朝 -Z = 面对岸上,敌机从 -Z = 岸上方向来。坐标系无需改动!
- 只需把地貌改成 -Z 方向是陆地(海岸)、+Z 方向是海洋

**当前地图系统不支持按关卡切换**:`createEnvironment()` 无参数,env/clouds 是 AppShell 级跨关卡共享。需改造(方案 C:最小改动 + 向后兼容)。

## 推荐方案:方案 C(最小改动 + 向后兼容)

### 核心思路
1. `createEnvironment(scene, renderer, envConfig=null)` 增加可选第三参,`null` 时行为完全等同原版(巴巴罗萨零影响)
2. AppShell `startLevel` 时按关卡 `environment.theme` 重建 env/clouds(主题不同才重建)
3. terrain.js 模块级 `COAST_CONFIG` 注入海岸模式(陆地+海洋分区 + 白崖)
4. 新建 ocean.js 海水渲染(顶点 sin 波动 + 跟随相机 + 雾气融合)

### 地貌坐标系
- 海岸线 `z = -1000`(玩家前方 1000 单位)
- z < -1000:陆地(白崖、绿色丘陵、英伦村庄),敌机在此区域(z ≈ -1300~-1900)
- z > -1000:海水平面(y=0,大平面 size=30000 远超地形,雾气遮盖营造无限延伸)
- 玩家 (0, 700, 0) 朝 -Z(海上,面对岸上)

## 改动文件清单(按依赖顺序)

### 1. `js/terrain.js` — 海岸线地貌

- 新增模块级 `COAST_CONFIG = null` + 导出 `setCoastConfig(cfg)` / `getCoastConfig()`
- `setCoastConfig` 切换时清空 `_hCache`(避免旧高度值污染)
- 原 barbarossa 高度逻辑提取为 `_computeLandHeight(x, z)`(私有,原封不动)
- `getTerrainHeight(x, z)` 顶层判断:`!COAST_CONFIG` 返回原版;否则按海岸线分区:
  - z > coastline + 60:海平面(返回 0)
  - z < coastline - 60:陆地 = `_computeLandHeight` + 白崖增益(sin 钟形剖面,峰值 cliffHeight=80,400m 后衰减为 0)
  - 过渡带 ±60m:smoothstep 插值(避免硬墙)
- `Terrain.create()` 顶点着色分支:Britain 模式海岸线附近用白垩岩色 `0xe8e4d8` + 崖顶草地,海滩沙色 `0xb0a888`
- 新增 `Terrain.isLand(x, z)`(供 Buildings 过滤海域) + `Terrain.dispose()`

### 2. `js/buildings.js` — 海域过滤 + 英伦调色板

- `_buildVillages` / `_buildForests` 候选位置增加 `terrain.isLand?.(cx, cz)` 检查(兼容旧版无该方法)
- 支持 `options.palette = 'britain'`:红砖墙 `0x8a4a3a` + 灰石板顶 `0x3a3a3a`
- 新增 `dispose(scene)` 方法

### 3. `js/ocean.js`(新建)— 海水渲染

- `Ocean` 类:PlaneGeometry(size=30000, segments=200) 顶点 sin 多频波动
- 顶点着色:近岸偏浅、远海偏深(层次感)
- `MeshStandardMaterial`(灰蓝 `0x4a6878`, opacity=0.92, roughness=0.35)
- `update(dt, camera)`:更新顶点 y + computeVertexNormals + 跟随相机 xz(避免边缘穿帮)
- `dispose()`:释放 geometry/material

### 4. `js/clouds.js` — 新增 dispose

- 新增 `dispose(scene)`:移除所有 cluster.group + 释放 material/textures

### 5. `js/environment.js` — 参数化 + disposeEnvironment

- `createEnvironment(scene, renderer, envConfig=null)`:cfg 主题分支
  - 天空色/雾色/太阳/光照可配置(原值作为默认)
  - Britain 主题:调 `setCoastConfig(...)` 注入海岸配置(必须先于 terrain.create())
  - 创建 Ocean(仅 Britain)
  - 返回对象新增 `ocean` + `envConfig` 字段(超集兼容)
- 新增 `disposeEnvironment(env, scene)`:集中释放 sky/ground/grid/buildings/ocean 资源

### 6. `js/game/GameRuntime.js` — ocean.update 集成

- `_update` 第 6 步云层跟随附近新增单行:`if (env.ocean) env.ocean.update(dt, camera)`

### 7. `js/app/AppShell.js` — 关卡级 env 重建

- import `disposeEnvironment`
- 新增 `_rebuildEnvironmentFor(levelConfig)`:
  - 比对 `levelConfig.environment?.theme` 与 `this.env?.envConfig?.theme`
  - 同主题跳过(同关卡重玩加速);不同则销毁旧 env/clouds → 创建新(传 envConfig)
- `startLevel` 早期调用 `_rebuildEnvironmentFor(levelConfig)`(在 `new GameRuntime` 之前)

## 关键参数速查

| 参数 | 值 | 说明 |
|---|---|---|
| coastline | -1000 | 玩家海上 1000 单位,敌机深入陆地 300 |
| cliffHeight | 80 | 白崖峰值 80m,空中俯瞰清晰 |

| 海洋 segments | 200 | 顶点 ~40k,性能可控 |
| 海洋 color | 0x4a6878 | 灰蓝海水 |
| 天空 topColor | 0x5a7a9a | 灰蓝 |
