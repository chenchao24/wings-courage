## 三、关键技术约定（硬约束，不可违反）

### 3.1 海洋/地形
- 海洋材质必须 `depthTest: true`（否则飞机渲染在海面下方）
- 地形 `SEA_BED` 必须 -30（非 -3，防止海洋与地形 Z-fighting）
- 海洋距离雾密度 `0.00012`（默认 0.0003 会导致高空过白）
- 海洋颜色 `0x1a3040`（深灰蓝）
- 海洋法线扰动用 4 层 vnoise 叠加 fbm + 36.87° 旋转矩阵消除网格感

### 3.2 模型加载与克隆
- **GLTF 模型必须缓存 + 克隆**（不能每实例重新加载）：`_gltfCache` Map 缓存模板，`SkeletonUtils.clone()` 克隆
- **克隆体必须深拷贝材质**：`cloneGltfScene()` 后逐 mesh `material.clone()`，否则桨叶 `opacity=0.22` 会传播到所有克隆体
- 模型缓存时机：`load()` 完成后、`_setupPropPivot()` 之前

### 3.3 螺旋桨
- `PROP_SPIN=300` rad/s（避开 125.66 频闪冻结点）
- 桨叶 `opacity=0.22`（低透明度让高速旋转视觉暂留叠加成模糊盘）
- 无动画轨道的敌机（yak1/yak3/spitfire）用 `_setupPropPivot` 固定旋转
- 喷火桨叶转速 95 rad/s（低于全局 300 呈现清晰旋转感）

### 3.4 对话系统
- 对话队列必须顺序播放（`_queueDialogs` + `_updateDialogQueue`），每句播完才下一句
- 接敌时必须播完 `interceptChat` 序列，胜利时播完 `victoryChat` 才显胜利界面
- 游戏停止时必须清空队列并重置状态，防止延迟回调
- 随机战斗喊话冷却 3-8 秒，击落最后一架（4/4）后关闭喊话
- 玩家控制必须锁定到 `interceptChat` 开始播放才解锁

### 3.5 敌机/友军渲染
- **敌机/友军 aimLift 恒为 0**（弹道=纯机头方向 `getAimDirection` 退化）
- 玩家 aimLift=0.12（座舱视角上抬），由 `GameRuntime.setCamMode` 动态设置
- 轰炸机自卫炮塔有独立 `muzzleDirs`（背/腹/侧后炮塔各自方向）

### 5.2 字段约定
- `autoOrient`：true=按螺旋桨质心 Box3 几何中心自动算偏航；false=用 `yawOffset` 手动值
- `userScale`：`3.6 × 真实最长维 / 9.92`（9.92m = Bf 109 翼展基准）
- `hideGear: true` + `hideGearNodes`：显式起落架节点列表
- `propNodes`：显式螺旋桨桨叶节点列表
- `muzzleOffsets`：枪口位置（body frame，机头=-Z）
- `muzzleDirs`：枪口独立方向（轰炸机炮塔用，战斗机 null 共用机头方向）
- `propSpinSpeed`/`propOpacity`/`propBlurDisc`/`propBlurStrength`：螺旋桨视觉参数

### 5.3 新增机型流程
1. `.glb` 放入 `model/` 目录
2. 打开 `model_tuner.html`，选模型加载
3. Tab① 调朝向（autoOrient 或手动 yaw）+ 缩放（按翼展）
4. Tab② 调枪口（战斗机/轰炸机模式）
5. Tab③ 标记起落架节点（若展开）
6. Tab④ 标记螺旋桨节点 + 调视觉参数
7. 点"📋 导出配置"→ 复制 → 粘贴到 `js/enemy.js` MODEL_CONFIGS
8. 若需性能参数，在 MODEL_SPECS 加配置

## 六、已知问题与注意事项

### 6.1 调试工具验证技巧
- `window.__tuner.muzzles` 在 `muzzles = preset.map(...)` 重新赋值后失效（旧引用），验证枪口数值应读 DOM UI（`#muz-list .muz-group input`）或 `muzCount` 文本
- 截图在高渲染负载时可能 IDE 超时，改用 `browser_evaluate` 读 DOM 状态验证

### 6.2 模型朝向校准
- `computeAutoOrient` 必须用 `Box3.setFromObject().getCenter()` 取**几何中心**，不能用 `getWorldPosition` 取 transform 原点（Blender 导出的 Object_X 原点可能在机尾，导致朝向反）
- 工具的 `computeAutoOrient` 已与 `aircraft.js _autoOrient` 同步

### 6.3 PowerShell 限制
- 不支持 `&&`、`grep`、`head`，用 `;`、`rg`、`Select-Object -First N` 替代
