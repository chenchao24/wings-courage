## 一、已完成工作

### 1. 地形系统（terrain.js）
- **kursk 草原主题**：`setTerrainTheme('kursk')` 激活
- **5色草原色板**：深绿(0x2e5a28) / 草绿(0x4a7a32) / 黄绿(0x8a9038) / 浅黄绿(0xb0a048) / 枯黄(0xc8b858)
- **农田沿路网分布**：总覆盖率 ~30%，集中在小路/支路周围
  - 预计算 128×128 距离场（`getKurskDistField`），双线性插值查询（性能优化）
  - 距路 <1500m 农田权重高，>3500m 基本无农田
- **田块形状**：长方形（x方向~454m × z方向~263m，长宽比1.7:1），路附近域扭曲产生异形四边形
- **田埂**：灰白色(0xd8d4cc)，~2.2m宽，75%概率出现，混合强度0.30-0.55
- **丘陵**：低矮稀疏（幅值48m，mask 0.60-0.78），大片平原台地

### 2. 路网系统（kurskRoads.js）
- **三级路网**：
  - 公路 highway：18m宽，灰白 0xd0ccc6（南北主干G1 + 东西支线G2/G3）
  - 土路 dirt：5m宽，中灰白 0xb8b4ae（D1-D6 乡间路）
  - 小路 trail：2.5m宽，暗灰白 0xa09890（T1-T8 田野小径）
- **路面材质**：MeshStandardMaterial，roughness=1.0，metalness=0（完全不反光）
- **砂石颗粒感**：4层多频率噪声（4m/1m/0.25m/0.06m 大石子→碎石→砂粒→尘土）
- **6顶点横截面结构**：
  ```
  扩散带(5m) → 路肩(3-5m) → 路面 → 路面 → 路肩(3-5m) → 扩散带(5m)
  α0.6→0     α1.0→0.7    α1.0   α1.0   α1.0→0.7       α0.6→0
  ```
- **边缘虚化**：alpha渐变 + 噪声扰动（非硬直边界）
- **贴地**：8m采样步长，每顶点独立采样 terrain.getHeight()
- **路网骨架**（terrain.js 中 KURSK_ROAD_SKELETON 与 kurskRoads.js 控制点严格一致）

## 五、技术要点

### 比例基准
- Bf109 翼展 9.92m → 游戏 3.6 单位
- 1m 真实 = 0.3629 游戏单位
- userScale 公式：`3.6 × 真实最长维 / 9.92`

### 关卡隔离原则（最高优先级）
- 改一关的配置/行为，绝不允许波及其他关卡
- 飞机相关最严格：敌机/友军/玩家参数按关卡独立配置
- 共享代码改动需验证全部已开放关卡（britain + barbarossa + kursk）

### 路网骨架一致性
- `terrain.js` 的 `KURSK_ROAD_SKELETON` 与 `kurskRoads.js` 控制点必须严格一致
- 路网用于：① 渲染道路 mesh ② 农田距离分布计算

### 涂装纹理共享
- 三种涂装纹理(german/soviet/wreck)各生成一张 CanvasTexture
- 同阵营所有坦克共用同一张纹理，无重复创建开销

### 地面模型放置待实现
- 当前仅 terrain_test.html 中预览（z=-400 网格排列）
- 正式实现需创建 `js/kurskGroundObjects.js` 模块
- 按区域批量放置，使用 InstancedMesh 优化性能
- 释放：GameRuntime.stop() 时 dispose
