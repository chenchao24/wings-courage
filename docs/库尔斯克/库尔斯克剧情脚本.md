# 《鏖战库尔斯克》剧情脚本（v1 初稿）

> **状态**：初稿，待细化。三段式节奏：高空制空 → 精英对决 → 长机离场 → 单人低空猎杀。
> **风格**：职业军人无线电通话，短句术语化，少加戏。玩家"老兵上士"身份，无新手教学味。
> **角色**：长机冯·莱纳上尉（带队/指令/负伤离场/胜利收尾无线电）+ 玩家上士 + 地面装甲矛头指挥。

## 实现所需的新机制

| 机制 | 现状 | 需要做的 |
|---|---|---|
| 波间"飞到触发点才刷下一波" | WaveDirector 全灭后自动 delayAfterWave 刷下一波 | 新增 gate 机制：第2波等玩家飞抵触发点才刷 |
| 长机巡航跟随 + 负伤离场 | 无友军战斗机 AI（FriendlyBomber 是脚本化平飞） | 新写长机演出逻辑：巡航在前 + 离场调头飞走。MVP 不开火，演出型参与 |
| IL-2 定时刷新 + 自行返航 | `_despawnRequested` 字段已存在 | IL-2 用 route 航线飞抵目标后请求脱离消失 |
| IL-2 后座自卫机枪 | attacker 类型 fire=null | 新增 attacker 对后半球自卫开火逻辑 |
| IL-2 装甲分区 | takeDamage 均匀扣血 | 新增正面减伤/翼侧正常伤害逻辑 |
| onEnemyKilled 按序播放 | 当前随机抽一条 | 小改 GameRuntime 支持按击落序号取台词（可选） |
| La-5FN 模型 | 无，用 yak7 替代 | wave.tier='elite' 体现强度，模型暂用 yak7 |
