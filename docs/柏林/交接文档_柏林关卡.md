### 5. 柏林防空走廊模式（#68）

`AntiAircraftFlak` corridor 模式（配置 `flak.corridor` 才启用，缺省=原"跟随玩家"逻辑不变）：
- 走廊 x -30000~15000（东缘=编队入口），沿 z=0 航线
- 每 3000m 触发一个 800m 区间（`segmentEvery/segmentLen`）；进入前 700m 开火、队过后 700m 停火（`leadIn/leadOut`）
- 爆点高度 = 编队均值 ±400m（`altSpread`）；密度 0.53 爆/s + 4.3 曳光/s = 原跟随玩家 2/3
- **表演击落**：深入走廊一半（`killAt 0.5`）时随机一架：3 团空爆 + 直接 `_enterCrash`，**不报 killed 事件，不计玩家积分**
- 视觉参数沿用库尔斯克观感（burst smokeColor/fireColor/salvo，tracer color/life/len）

## 五、技术要点

### 关卡隔离原则（最高优先级）
- 本关所有设置独立，不影响第 1/2/3 关：`theme:'berlin'` 走 BerlinGround 分支、`combatAlt`/`flak.corridor`/`bomberStream`/`escortP51`/`wingmen262`/`opening`/`berlinChatter`/`berlinMusic`/`intercept`/`downed` 全部门控，仅本关配置
- 共享文件仅加"缺省关闭/缺省原值"门控分支（如 `AntiAircraftFlak` 不配 `corridor` = 原跟随玩家行为；`VaporTrail` 不配 `vaporAltMax` = 原 4500m 上限）
- 改共享代码后必跑：`test_berlin_level.py` + `test_campaign_regression.py`（四关行为不变）

### 配置门控清单（GameRuntime）
柏林关配置块 → GameRuntime 门控创建/推进/释放：
- `bomberStream` → bomberStream 数组 + 每帧推进 + 命中检测
- `escortP51` → P51EscortSquadron 创建（bomberStream 后）+ 每帧推进（先于僚机）+ 命中检测两块（玩家子弹 vs P-51；P-51 子弹 vs 玩家）+ 雷达红点 + 咬尾锁定警告
- `wingmen262` → Wingman262Squadron 创建 + 每帧推进 + B-17 炮塔多目标透传
- `opening` → BerlinOpening 创建（鸭式 CinematicSystem 接线：锁输入/相机委托/准星隐藏/ESC·C 键转发）
- `berlinChatter` → BerlinChatter 创建 + 事件入口接线
- `berlinMusic` → AppShell._playCombatMusic 跳过旧 playMusic（避免双轨叠加）
- `intercept` → HudController 拦截进度 UI + 每帧同步 P-51 拦截进度
- `combatAlt` → CombatAltRule 创建
- `downed` → HP=0 倒计时流程
- `sandbox: true` → GameRuntime 跳过胜利结算（无敌机波次）

### 模型管线坑
- **B-17**：`helice03_FACES01-FACES` 不能删（`_setupPropPivot` 算 pivot 包围盒）；4 个桨叶组节点名是 pivot 旋转查找键，合并必须绕过；重跑前不要删 `b17.original.glb`
- **P-51**：autoOrient 关键词匹配不到 P-51 节点 → 用 yawOffset=134 兜底；座舱盖 VIFS03 独立成组（近景透明排序安全）；双模糊盘 Cylinder15/16 合并为单节点 `p51_propdisc`（未来 `propNodes:['p51_propdisc']` 即可转桨）；回退：`p51.original.glb` 复制回 `p51.glb`
- **Me 262**：spec-gloss 旧格式，已转 PBR；无螺旋桨节点（喷气机），`propNodes:[]`

### 编队跟随教训（#72/#73）
- 纯距离正反馈（`base+dist×0.15` 恒≥长机速度）→ 超前永不减速 → 跑飞
- 指数低通（λ=5/s）追踪以 150m/s 平移的槽位 → 稳态滞后 ≈ v/λ ≈ 30m
- **正确做法**：沿航向带符号修正（落后加速/超前减速）+ 平移前馈 `v×(1/λ)` + 死区内速度方向对齐长机前向 + 残差极缓回拉

### 表演性质成立机制
- 僚机 262 子弹无任何命中检测路径；僚机自身不被受击检测
- P-51 子弹真实弹道（继承本机速度），只结算玩家；AI 僚机无命中路径
- 柏林防空 corridor 表演击落不报 killed 事件，不计玩家积分
