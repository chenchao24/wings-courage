# 战斗喊话
1.随机战斗报点：随机由2,3,4号机汇报敌机方位：内容为：x号（不包括队长1号），X点钟 注意！（时间间隔为20-30秒）

2.玩家被咬尾，当玩家被敌机跟随咬尾，距离小于400米时，【霍夫曼（2 号）】喊话：“队长，X点钟，敌机,注意规避！”

3.随机战斗事件: 随机由2,3,4号机喊话：击伤轰炸机，X点钟方向！/击伤护航战斗机！/我被咬住了！/ X号（喊话者） 请求支援！/  （随机时间为40-50秒）/ X号（除喊话者以外飞机） 干得好！

4.击落喊话：玩家击落/击伤敌机，由玩家自己（1号）喊话：雨燕1号，击落一架轰炸机！/战斗机！ /击伤轰炸机一架！已脱离编队！/ 击伤战斗机，已脱离战场！

5.玩家击落和击伤喊话后，触发基地回复：收到，指挥官！干的漂亮！

6.玩家被击落（hp为0，非坠毁状态时触发）：雨燕1号，飞机受损，我将跳伞，2号接管指挥权！
